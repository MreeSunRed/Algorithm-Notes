# 回文链表 (Palindrome Linked List)

> LeetCode 234 · 难度：简单 · 标签：链表、双指针、栈、递归

## 题目

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

```
输入: 1 → 2 → 2 → 1
输出: true

输入: 1 → 2
输出: false
```

## 思路

链表的痛点是**只能单向遍历**，没法像数组那样从两端同时向中间靠拢。所有解法本质上都在解决同一个问题：**如何获得「从后往前」的访问能力**。

### 思路一：转成数组（最直观，O(n) 空间）

先把所有值抄进列表，问题立刻退化成「判断数组是否回文」：

```python
nums = []
while head != None:
    nums.append(head.val)
    head = head.next

for i, val in enumerate(nums):
    if val != nums[-1 * (i + 1)]:   # 与对称位置比较
        return False
    if i >= len(nums) / 2:          # 走到中线就停
        return True
```

`nums[-1 * (i + 1)]` 就是 `nums[-i-1]`：`i = 0` 时取最后一个，`i = 1` 时取倒数第二个，正好和正着数的 `nums[i]` 对称。

**为什么到中线就能返回 `True`？** 对称比较是一对一对做的，走到中线说明所有对都配上了，后半段与前半段必然一致，没必要再重复比较一遍。

- 时间 O(n)，空间 O(n)

**优点**：直观、好写、不容易错。
**缺点**：额外开了 O(n) 空间，不满足「能否用 O(1) 空间解决」的进阶要求。

### 思路二：数长度 + 反转后半段（本仓库实现，O(1) 空间）

既然链表不能倒着走，那就**把后半段反过来**，就能从两端向中间比较了。整个流程分四步：

1. **数长度**：用游标 `hnode` 遍历一次得到节点数 `nums`，同时**保留 `head` 不动**
2. **定位中点**：从 `head` 出发走 `ceil(n/2)` 步，得到 `midnode`
3. **反转后半段**：复用 [206. 反转链表](09-反转链表.md) 的迭代写法，`tailA` 是反转后的头
4. **两端比较**：`midnode` 从反转后的后半段出发，`head` 从原头出发，逐个比较；后半段走完则全部匹配

**中点落在哪里？** 循环条件是 `i < nums/2`：

| 长度 | 循环执行次数 | `midnode` 位置 | 处理 |
|------|:---:|------|------|
| 偶数 `2k` | `k` | 下标 `k`，后半段起点 | 反转 `k` 个，比较 `k` 对 |
| 奇数 `2k+1` | `k+1` | 下标 `k+1`，正中点的**后一个** | 反转 `k` 个，中间节点被跳过 |

奇数长度跳过正中间那个节点是安全的：它只和自己对应，比较与否都不影响结论。

```python
nums = 0
hnode = head
while hnode != None:      # 用 hnode 数长度，head 保留给最后的比较
    hnode = hnode.next
    nums += 1

midnode = head
i = 0
while i < nums/2:         # 走到后半段的起点
    midnode = midnode.next
    i += 1
```

**定位中点的另一种写法：快慢指针。** 让 `fast` 每步走 2、`slow` 每步走 1，`fast` 到头时 `slow` 正好在后半段起点：

```python
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

两种方式都是 O(n) 时间、O(1) 空间：数长度更直白，快慢指针少一次完整遍历，是面试里更常见的写法。

### 思路三：栈

把前半段压栈，再与后半段逐个弹出比较。时间 O(n)、空间 O(n)。思路直观，但和转数组没有本质区别，面试中通常作为过渡方案提及。

## 复杂度

| 解法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 数长度 + 反转后半段（本仓库） | O(n) | **O(1)** | 最优空间，逻辑直白 |
| 快慢指针 + 反转 | O(n) | **O(1)** | 同上，定位中点少一次遍历 |
| 转数组 | O(n) | O(n) | 最简单，先保证正确 |
| 栈 | O(n) | O(n) | 直观，但无空间优势 |

## 代码

```python
class Solution(object):
    def isPalindrome(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: bool
        """
        nums = 0
        hnode = head
        while hnode != None:
            hnode = hnode.next
            nums += 1
        i = 0
        midnode = head
        while i < nums / 2:
            midnode = midnode.next
            i += 1
        tailA = None
        while midnode != None:
            p = midnode
            midnode = midnode.next
            p.next = tailA
            tailA = p
        midnode = tailA
        while midnode != None:
            if midnode.val != head.val:
                return False
            midnode = midnode.next
            head = head.next
        return True
```

## 易错点

- **数长度时不能直接走 `head`**：如果写成 `while head != None: head = head.next`，链表头就被永久丢掉了，后面没有起点可以比较。必须像本实现这样用游标 `hnode = head` 复制一份再走。这是本实现最容易踩的坑。
- **`nums / 2` 是浮点除法，中点位置要想清楚**：奇数长度时循环会多走一步，`midnode` 落在正中点的**后一个**，正好跳过中间节点；若改成 `nums // 2`，`midnode` 会落在正中间，反转后中间节点与自己比较，结论同样正确。两种写法都对，但要清楚差异。
- **单节点时 `midnode` 会变成 `None`**：`nums/2 = 0.5`，定位循环执行一次，`midnode` 直接走到空；反转和比较都跳过，返回 `True`。单节点天然回文，这是正确行为。
- **反转前先保存后继**：`p = midnode; midnode = midnode.next; p.next = tailA`，顺序不能反 —— 先拿到「下一站」，再改指针，否则断链。
- **比较循环的终止条件是 `midnode != None`**：后半段长度不会超过前半段（偶数等长、奇数少一个），所以 `head` 一定够走，不会越界。
- **奇数长度的中间节点不用比较**：它只和自己对应，跳过与否结果相同，不必额外处理。
- **末尾必须 `return True`**：能走到这里说明所有对称位置都匹配。写成空 `return` 会返回 `None`，LeetCode 当假值处理 —— 之前的数组写法就在这里踩过单节点的坑。
- **会修改链表结构**：反转后半段改变了节点的 `next` 指针。LeetCode 不检查原结构；若调用方之后还要复用这条链表，需要把后半段再反转恢复。
- **只比较 `val`，不比较节点身份**：回文判断依据是值；两条不同链表也可以值相同。
- **空链表**：`nums = 0`，所有循环跳过，返回 `True`（空链表视为回文）。LeetCode 虽然保证至少一个节点，但本实现天然兼容。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[1,2,2,1]` | `true` | 偶数长度回文 |
| `[1,2,3,2,1]` | `true` | 奇数长度回文，中间节点被跳过 |
| `[]` | `true` | 空链表，本实现天然兼容 |
| `[1,2]` | `false` | 偶数长度非回文 |
| `[1]` | `true` | 单节点 |
| `[1,1,2,1]` | `false` | 前半对称、后半破坏 |
| `[1,2,1,1]` | `false` | 镜像位置不匹配 |
