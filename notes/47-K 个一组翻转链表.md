# K 个一组翻转链表 (Reverse Nodes in k-Group)

> LeetCode 25 · 难度：困难 · 标签：链表、递归、指针操作

## 题目

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，返回修改后的链表。

- `k` 是正整数，且 `k <= 链表长度`
- 如果节点总数不是 `k` 的整数倍，**最后剩余的节点保持原有顺序**
- 不能只修改节点内部的值，必须实际交换节点

```
输入: head = [1,2,3,4,5], k = 2
输出: [2,1,4,3,5]

输入: head = [1,2,3,4,5], k = 3
输出: [3,2,1,4,5]

输入: head = [1,2,3,4,5], k = 1
输出: [1,2,3,4,5]
```

## 思路

### 整体结构

问题可以拆成两步：

1. **判断剩余节点够不够 k 个**：不够就原样返回，这是递归的出口
2. **翻转当前这 k 个节点**，再把「翻转后的尾巴」接到「下一组的结果」上

### 本仓库实现：递归

```python
def reserveK(root, k):
    tail = root
    count = k
    while tail != None and count > 1:
        tail = tail.next
        count -= 1
    if count > 1 or tail == None:
        return root
    ...
```

第一段从 `root` 出发走 `k - 1` 步找到这一组的第 k 个节点 `tail`。如果中途走到 `None`，说明剩余不足 k 个，直接返回 `root`，保持原序。

```python
    after_node = tail.next
    head = None
    tail_root = root
    head_tail = tail
    count = k
    while count > 0:
        p = root
        root = root.next
        p.next = head
        head = p
        count -= 1
```

第二段就是标准的链表反转，只不过限定翻转 `k` 次：

- `tail_root = root`：原组的第一个节点，翻转后会变成**这一组的尾巴**
- `head_tail = tail`：原组的第 k 个节点，翻转后会变成**这一组的头**
- `after_node`：下一组的入口，反转前先保存，否则会被指针覆盖

```python
    tail_root.next = reserveK(after_node, k)
    return head_tail
```

最后把这一组的尾巴接到递归处理后的下一组，返回这一组的新头。

以 `[1,2,3,4,5]`、`k = 2` 为例：

| 调用 | 找到的 tail | after_node | 反转结果 | 返回 |
|------|:-----------:|:----------:|----------|:----:|
| `reserveK(1,2)` | 2 | 3 | `2 → 1` | 2 |
| `reserveK(3,2)` | 4 | 5 | `4 → 3` | 4 |
| `reserveK(5,2)` | 不足 2 个 | — | 原样 | 5 |

从内向外接回去：`3.next = 5`、`1.next = 4`，最终得到 `2 → 1 → 4 → 3 → 5`。

### 迭代写法（避免递归深度）

```python
dummy = ListNode(0)
dummy.next = head
group_prev = dummy

while True:
    kth = group_prev
    for _ in range(k):
        kth = kth.next
        if kth is None:
            return dummy.next          # 剩余不足 k 个，保持原序

    group_next = kth.next
    prev, cur = group_next, group_prev.next
    for _ in range(k):                 # 翻转这一组，并接到 group_next 上
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt

    first = group_prev.next            # 翻转后变成这一组的尾巴
    group_prev.next = kth              # kth 是翻转后的新头
    group_prev = first
```

- 时间 O(n)，空间 O(1)
- 每一步都先确认剩余长度够 k，再动手翻转，天然满足「不足 k 个保持原序」

## 复杂度

- **时间 O(n)**：每个节点被遍历、翻转各常数次
- **空间 O(n/k)**（递归写法）：递归深度等于组数；迭代写法为 O(1)

## 代码

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def reverseKGroup(self, head, k):
        """
        :type head: Optional[ListNode]
        :type k: int
        :rtype: Optional[ListNode]
        """

        def reserveK(root, k):
            tail = root
            count = k
            while tail != None and count > 1:
                tail = tail.next
                count -= 1
            if count > 1 or tail == None:
                return root
            after_node = tail.next
            head = None
            tail_root = root
            head_tail = tail
            count = k
            while count > 0:
                p = root
                root = root.next
                p.next = head
                head = p
                count -= 1
            tail_root.next = reserveK(after_node, k)
            return head_tail

        return reserveK(head, k)
```

## 易错点

- **最后不足 k 个也翻转了**：必须先数够 k 个再翻，否则会破坏「保持原有顺序」的要求。
- **没保存 `tail.next`**：反转 `k` 个节点前必须记住下一组的入口 `after_node`，否则链表断掉。
- **接错组间指针**：翻转后原组的第一个节点变成尾巴，应该用 `tail_root.next` 去接下一组，而不是原来的头。
- **返回错头节点**：每一组翻转后的新头是原来的第 k 个节点 `head_tail`；整个链表的新头是第一组的 `head_tail`。
- **`k = 1`**：每组只有一个节点，翻转后不变。代码能正确处理，但会为每个节点递归一次，深度为 n。
- **`k = n`**：整条链表翻转一次，结果就是整体反转。
- **空链表**：`tail = None`，直接返回 `None`，不会进入反转循环。
- **递归深度**：本题节点数上限 5000，当 `k = 1` 时递归深度为 5000，超过 Python 默认递归上限（约 1000）会抛 `RecursionError`。生产代码或极端数据建议用迭代写法。
- **只交换值**：题目要求实际交换节点；只改 `val` 不符合要求。
- **数长度时多走一步**：找到第 k 个节点只需要从 `root` 走 `k - 1` 步，多走一步会越界或漏掉元素。
