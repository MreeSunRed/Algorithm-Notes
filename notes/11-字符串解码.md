# 字符串解码 (Decode String)

> LeetCode 394 · 难度：中等 · 标签：栈、字符串、递归

## 题目

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：`k[encoded_string]`，表示方括号内部的 `encoded_string` 重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。此外，原始数据不包含数字，所有的数字只表示重复的次数 `k`，例如不会出现像 `3a` 或 `2[4]` 的输入。

```
输入: s = "3[a]2[bc]"
输出: "aaabcbc"

输入: s = "3[a2[c]]"
输出: "accaccacc"

输入: s = "2[abc]3[cd]ef"
输出: "abcabccdcdcdef"
```

## 思路

### 为什么用栈

编码是**嵌套**的：`3[a2[c]]` 里，内层的 `2[c]` 必须先展开，外层才能拿到完整的 `a2[c]` 再重复 3 次。

「最后出现的 `[`，最先被对应的 `]` 闭合」—— 这正是后进先出。所以从左到右扫描，遇到 `]` 就说明**最内层**的一组编码结束了，此时从栈里把这一组的内容和重复次数取出来，展开后再放回栈中，交给外层继续处理。

### 本仓库的实现：单栈 + 两次反转

扫描字符串：

| 遇到 | 动作 |
|------|------|
| 普通字符 / `'['` / 数字 | 直接压栈 |
| `']'` | 开始展开最内层：① 弹出内容直到 `'['` ② 弹出 `'['` ③ 弹出连续数字 ④ 重复内容 ⑤ 压回栈 |

**关键细节一：内容弹出后是反序的。**

以 `"ab"` 为例，它在栈里是 `['a', 'b']`，弹出到 `temp` 后变成 `['b', 'a']`。重复 `temp * mul` 得到的仍是「反序内容的重复」。最后用 `while temp: stack.append(temp.pop())` 压回去 —— `pop()` 从末尾取，等于**再反转一次**，顺序就恢复成 `"abab"` 了。

如果直接把 `temp` 顺序压回去（或 `stack.extend(temp)`），内容会整体反掉，这是本实现最容易看错的地方。

**关键细节二：数字也要反序。**

`"12[a]"` 扫描到 `']'` 时，栈顶依次是 `'2'`、`'1'`。弹出得到 `['2', '1']`，必须 `num[::-1]` 还原成 `['1', '2']`，再按 `mul = mul*10 + int(d)` 累乘，才能得到 12。**多位数必须专门处理**，不能只取一位。

### 更直观的双栈写法

把「待展开的字符串」和「重复次数」分开存，可以避免两次反转：

```python
class Solution(object):
    def decodeString(self, s):
        counts, parts = [], ['']
        num = 0
        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)      # 多位数累加
            elif ch == '[':
                counts.append(num)
                parts.append('')
                num = 0
            elif ch == ']':
                cur = parts.pop()
                parts[-1] += cur * counts.pop()
            else:
                parts[-1] += ch
        return parts[0]
```

- `parts[-1]` 始终是「当前层正在拼的字符串」
- 遇到 `[` 就开新的一层，遇到 `]` 就把当前层重复后并回上一层
- 数字在扫描过程中直接累加，天然支持多位数

## 复杂度

设 `n = len(s)`，`m` 为解码后的字符串长度（LeetCode 保证 `m <= 10^5`）。

- **时间 O(m)**：每个输出字符至少被写入一次；展开重复时的工作量与产生的内容长度成正比
- **空间 O(m)**：栈中最多同时保存解码结果；返回值本身也占 O(m)

注意 `m` 可能远大于 `n`：例如 `9[9[9[a]]]` 的输出长度是 729，而输入只有 9 个字符。所以复杂度必须用**输出长度**来度量，不能只看输入。

## 代码

```python
class Solution(object):
    def decodeString(self, s):
        """
        :type s: str
        :rtype: str
        """
        stack = []
        for i in range(len(s)):
            if s[i] != ']':
                stack.append(s[i])
            else:
                temp = []
                while stack[-1] != '[':
                    temp.append(stack.pop())
                stack.pop()
                num = []
                while stack != [] and stack[-1].isdigit():
                    num.append(stack.pop())
                num = num[::-1]
                mul = 0
                for i in num:
                    mul = mul * 10 + int(i)
                temp = temp * mul
                while temp != []:
                    stack.append(temp.pop())
        return "".join(x for x in stack)
```

## 易错点

- **只处理一位数字**：`10[a]`、`100[leetcode]` 在题目中合法，必须把连续的数字全部取出来。本实现用 `while stack and stack[-1].isdigit()` 收集，再用 `[::-1]` 还原顺序。
- **数字弹出后是反序的**：栈里是 `'1'`、`'2'`，弹出得到 `'2'`、`'1'`。不反转就按 `2*10+1 = 21` 算，答案会错。也可以边弹边用位权累加，但 `[::-1]` 更直观。
- **内容压回时又反了一次**：`temp` 里是反序内容，`temp * mul` 后必须用 `pop()` 逐个压回，才能恢复正序。直接 `stack.extend(temp)` 会让内容永久反掉。
- **嵌套必须从内向外展开**：遇到 `]` 立即处理最内层，展开后的结果留在栈上供外层使用。不要试图从外向内解析。
- **`while stack[-1] != '['` 没有判空**：题目保证输入合法，所以一定能找到 `[`。若要做健壮版本，应加 `stack` 非空判断，避免非法输入时 `IndexError`。
- **循环变量 `i` 被内层复用**：代码里 `for i in range(len(s))` 和外层同名的 `for i in num` 共用了变量名。Python 的 `for` 每轮从迭代器重新取值，所以结果不受影响；但同名变量容易让人误读，建议内层改成 `d`。
- **`k = 1` 或没有数字**：题目保证 `k` 是正整数，且每个 `[...]` 前都有数字。若输入不合法（例如 `[a]`），`mul` 会保持 0，内容会被清空 —— 这是约束之外的情况。
- **用字符串加法逐字符拼接**：Python 的字符串不可变，循环里 `res += ch` 可能退化为 O(n²)。本实现用列表 + `"".join()`，是正确做法。
- **空字符串**：`s = ""` 时循环不执行，返回 `""`，正确。
