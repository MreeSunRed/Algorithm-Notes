# 环形链表 II (Linked List Cycle II)

> LeetCode 142 · 难度：中等 · 标签：链表、哈希表、双指针、数学

## 题目

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

**不允许修改**链表。

```
输入: head = [3,2,0,-4], pos = 1
输出: 返回索引为 1 的链表节点
解释: 链表中有一个环，其尾部连接到第二个节点。
```

## 思路

### 思路一：哈希表

从 `head` 开始遍历，把每个节点对象存入 `set`。**第一个重复出现的节点**就是入环点：第一次走到它，说明已经绕回了环的入口；而环外的节点只会被访问一次。

- 时间 O(n)，空间 O(n)
- 必须按**节点身份**判重，不能按 `val`（值可能重复）
- 思路直观，面试可以先说这个

### 思路二：快慢指针（Floyd，O(1) 空间）

[141. 环形链表](16-环形链表.md) 只用快慢指针判断「有没有环」；本题还需要找出**环的入口**。在相遇之后，需要再做一次巧妙的操作：

> **让一个指针从 `head` 出发，另一个指针从相遇点出发，每次都走 1 步，它们相遇的位置就是环的入口。**

先看结论怎么来的。

### 数学推导

设：

- 从 `head` 到环入口的距离为 `a`
- 从环入口到相遇点的距离为 `b`
- 环的长度为 `c`

当快慢指针相遇时：

- 慢指针走了 `a + b`
- 快指针走了 `a + b + k·c`（`k` 是快指针在环里多绕的圈数）
- 快指针速度是慢指针的 2 倍：

```
a + b + k·c = 2(a + b)
        k·c = a + b
          a = k·c - b = (k - 1)·c + (c - b)
```

这个等式说明：**从 `head` 走 `a` 步到入口**，和**从相遇点走 `c - b` 步到入口**，在模 `c` 意义下是同一个位置。

所以让：

- 指针 `res` 从 `head` 出发
- 指针 `last`（慢指针）从相遇点出发

两者每次都走 1 步。`res` 走完 `a` 步时，`last` 恰好走完 `c - b` 步（再加上若干整圈），两者在**环入口**重合。

### 本仓库实现

代码分两阶段：

**阶段一：找相遇点**。`first` 是快指针（每轮走 2），`last` 是慢指针（每轮走 1）。快指针每一步都要检查 `None`，无环时提前返回。

**阶段二：找入口**。`res = head`，与慢指针 `last` 同步每次走 1，直到 `res is last`，返回 `res`。

> 变量名说明：代码里 `first` 实际是**快指针**，`last` 是**慢指针**，名字容易误解。功能上没有问题，阅读时对照「快 / 慢」即可。

## 复杂度

| 解法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 哈希表 | O(n) | O(n) | 直观，第一个重复节点即入口 |
| 快慢指针（本仓库） | O(n) | **O(1)** | 最优，需要数学推导 |

- 阶段一慢指针最多走 O(n) 步；阶段二最多再走 `a ≤ n` 步
- 快慢指针只用了几个节点引用

## 代码

```python
class Solution(object):
    def detectCycle(self, head):
        """
        :type head: ListNode
        :rtype: ListNode
        """
        first = head
        last = head
        while first != None:
            first = first.next
            if first == None:
                return None
            first = first.next
            last = last.next
            if last == None:
                return None
            if last == first:
                break
        if first == None:
            return None
        res = head
        while res != last:
            res = res.next
            last = last.next
        return res
```

## 易错点

- **阶段二从相遇点出发，不是从快指针出发**：必须用慢指针（或任一相遇时的指针）作为第二阶段的起点，配合 `head` 同步前进。
- **返回的是节点对象，不是下标或值**：LeetCode 会校验返回节点的身份。测试时应使用 `result is expected_node`，而不是比较 `val`。
- **无环时返回 `None`**：循环中要检查快指针是否走到 `None`；本实现在第一次和第二次前进后都做了检查，安全。
- **快指针第二次前进前必须判空**：`first = first.next` 之后立刻判断 `first == None`，否则再取一次 `.next` 会对 `None` 取属性。
- **空链表**：`head = None` 时循环不执行，最后的 `if first == None` 返回 `None`，正确。
- **单节点自环**：`head.next = head` 时，快慢指针在第一步就相遇，阶段二 `res == last == head`，直接返回 `head`，正确。
- **`last == None` 的检查是冗余的**：在合法单链表中，如果慢指针为空，快指针必然更早遇到空。保留它不影响正确性，但可以删掉简化代码。
- **哈希表必须存节点对象**：用 `val` 判重会把「值重复但无环」误判成有环；用节点身份才能对应「同一个节点被再次访问」。
- **不要修改链表**：题目明确不允许修改，快慢指针天然满足。
- **`pos` 不是参数**：不要读取 `pos`，函数只接收 `head`。

## 边界测试

| 输入 | 输出 | 说明 |

| `[]` | `None` | 空链表 |
