# 从前序与中序遍历序列构造二叉树 (Construct Binary Tree from Preorder and Inorder Traversal)

> LeetCode 105 · 难度：中等 · 标签：树、递归、分治、哈希表

## 题目

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的**先序遍历**，`inorder` 是同一棵树的**中序遍历**。请构造二叉树并返回其根节点。

**约束**：`preorder` 和 `inorder` 均**没有重复元素**。

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]

输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

## 思路

### 两条关键性质

1. **先序的第一个元素就是根节点**：`preorder[0] = root`
2. **中序中根节点把左右子树分开**：根左边是左子树的中序，根右边是右子树的中序

因为元素不重复，根节点在中序里的下标可以唯一确定左右子树的大小。

设根在中序中的下标为 `index_in`：

- 左子树节点数 = `index_in`
- 左子树先序 = `preorder[1 : index_in + 1]`
- 左子树中序 = `inorder[:index_in]`
- 右子树先序 = `preorder[index_in + 1:]`
- 右子树中序 = `inorder[index_in + 1:]`

然后对左右子树递归执行同样的拆分，空区间返回 `None`。

### 本仓库实现：递归 + 切片

```python
def build(preorder, inorder):
    if not preorder:
        return None
    root = TreeNode(preorder[0])
    index_in = inorder.index(preorder[0])
    root.left = build(preorder[1 : index_in + 1], inorder[:index_in])
    root.right = build(preorder[index_in + 1 :], inorder[index_in + 1 :])
    return root
```

以经典用例为例：

```
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]
```

| 子树 | 根 | index_in | 左子树 pre / in | 右子树 pre / in |
|------|:--:|:--------:|-----------------|-----------------|
| 整棵树 | 3 | 1 | `[9]` / `[9]` | `[20,15,7]` / `[15,20,7]` |
| 右子树 | 20 | 1 | `[15]` / `[15]` | `[7]` / `[7]` |

递归构造出的结构：

```
      3
     / \
    9   20
       /  \
      15   7
```

### 本仓库的修正说明

本地原始版本有两处会导致错误：

1. `inorder.index([preorder[0]])` 把根值包成了列表 `[3]`，而中序里存的是整数 `3`，会抛 `ValueError`。应写成 `inorder.index(preorder[0])`。
2. `preorder[1:index_in]` 是左闭右开区间，会丢掉左子树的最后一个节点。左子树有 `index_in` 个节点，正确切片是 `preorder[1:index_in + 1]`。

仓库中的题解已经修正这两处，并通过了全部测试。

### 优化写法：哈希表 + 下标区间

切片和 `inorder.index` 每次都要 O(n)，最坏会退化到 O(n²)。可以预先建立「值 → 中序下标」的哈希表，递归时只传四个下标，不复制数组：

```python
class Solution(object):
    def buildTree(self, preorder, inorder):
        index = {val: i for i, val in enumerate(inorder)}

        def build(pre_left, pre_right, in_left, in_right):
            if pre_left > pre_right:
                return None
            root_val = preorder[pre_left]
            root = TreeNode(root_val)
            mid = index[root_val]
            left_size = mid - in_left
            root.left = build(pre_left + 1, pre_left + left_size,
                              in_left, mid - 1)
            root.right = build(pre_left + left_size + 1, pre_right,
                               mid + 1, in_right)
            return root

        return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

- 时间 O(n)：每个节点只处理一次，哈希查询 O(1)
- 空间 O(n)：哈希表 + 递归栈
- 不产生切片，适合 `n = 3000` 的约束

## 复杂度

| 写法 | 时间 | 空间 |
|------|:----:|:----:|
| 递归 + 切片（本仓库） | 最坏 O(n²)，平衡时 O(n log n) | 最坏 O(n²) 切片，递归栈 O(n) |
| 哈希表 + 下标区间 | O(n) | O(n) |

## 代码

```python
# Definition for a binary tree node.
class TreeNode(object):
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution(object):
    def buildTree(self, preorder, inorder):
        """
        :type preorder: List[int]
        :type inorder: List[int]
        :rtype: Optional[TreeNode]
        """

        # pre 中左右[3,9,20,15,7]
        # in 左中右[9,3,15,20,7]
        # [3,9,20,null,null,15,7]
        def build(preorder, inorder):
            if not preorder:
                return None
            root = TreeNode(preorder[0])
            index_in = inorder.index(preorder[0])
            root.left = build(preorder[1 : index_in + 1], inorder[:index_in])
            root.right = build(preorder[index_in + 1 :], inorder[index_in + 1 :])
            return root

        return build(preorder, inorder)
```

## 易错点

- **`inorder.index` 传入列表**：`inorder.index([preorder[0]])` 会去找一个列表元素，直接抛 `ValueError`；要传值本身。
- **左子树先序切片右边界少 1**：`preorder[1:index_in]` 只有 `index_in - 1` 个元素，会丢掉左子树最后访问的节点。正确是 `preorder[1:index_in + 1]`。
- **用 `preorder[0]` 之外的元素当根**：先序的第一个元素才是根。
- **左右子树的中序区间都从 0 开始**：左子树取 `[:index_in]`，右子树取 `[index_in + 1:]`，右子树要跳过根。
- **把「先序」和「中序」的角色弄反**：先序定根，中序定左右边界；反过来（后序 + 中序）是 106 题。
- **空区间判断**：用 `if not preorder` 或 `if pre_left > pre_right`，不要只判断 `None`。
- **元素重复**：题目保证无重复；若有重复，`index` 无法唯一确定根，需要额外信息。
- **递归深度**：`n <= 3000`，链状树深度可达 3000，超过 Python 默认递归上限（约 1000）。极端数据需要迭代写法或调整递归上限。
- **切片带来的性能问题**：每层都复制数组，斜树会退化成 O(n²) 时间和空间；大数据建议用下标区间写法。
- **只返回根节点**：构造完成后要保证左右子树都正确挂接，不要只建出根。
