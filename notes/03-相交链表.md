# 相交链表 (Intersection of Two Linked Lists)

> LeetCode 160 · 难度：简单 · 标签：链表、哈希表、双指针

## 题目

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

题目数据**保证整个链式结构中不存在环**。函数返回结果后，链表必须**保持其原始结构**。

```
A:  a1 → a2 ↘
             c1 → c2 → c3
B:  b1 → b2 → b3 ↗
```

答案是 `c1`，不是 `c2`/`c3`。

## 思路一：哈希集合（本仓库实现）

**核心洞察**：如果两个链表相交，那么从交点开始，它们**共享同一段内存**—— 是同一个节点对象，而不只是值相等。

所以问题变成：「找出同时存在于两条链上的第一个节点」。

做法：

1. 遍历 A，把每个节点对象存入 `set`
2. 遍历 B，第一个出现在 `set` 里的节点就是交点

Python 的 `set` 用哈希 + `__eq__` 判等，而 `ListNode` 未重写 `__eq__`，默认按**身份**（`id`）比较。这正好符合需求 —— 能正确区分「值相同但不是同一个节点」的情况。

**为什么存节点对象而不是 `val`？** 两条链表里完全可能出现值相同的不同节点（例如两个独立的 `val=1` 的头节点）。存值会误判成相交。

## 复杂度

- **时间 O(m + n)**：A 遍历一次，B 最坏遍历一次
- **空间 O(m)**：需要存下 A 的全部节点

## 思路二：双指针（O(1) 空间，更优）

哈希集合要多花 O(m) 空间。有个很巧的 O(1) 解法：

设 A 独有部分长 `a`，B 独有部分长 `b`，公共部分长 `c`。

让指针 `p` 走完 A 后**跳到 B 的头**继续走，指针 `q` 走完 B 后**跳到 A 的头**继续走。

- `p` 走过的总路程：`a + c + b`
- `q` 走过的总路程：`b + c + a`

两者**相等**。所以它们必然同时到达交点 —— 若不相交（`c = 0`），则同时到达 `None`，`while` 条件不成立，自然退出并返回 `None`。

```python
class Solution(object):
    def getIntersectionNode(self, headA, headB):
        if not headA or not headB:
            return None
        p, q = headA, headB
        while p is not q:
            p = p.next if p else headB
            q = q.next if q else headA
        return p
```

- **时间 O(m + n)**，**空间 O(1)**

## 本仓库代码

```python
class Solution(object):
    def getIntersectionNode(self, headA, headB):
        """
        :type head1, head1: ListNode
        :rtype: ListNode
        """
        s = set()
        nodea = headA
        nodeb = headB
        while nodea != None:
            s.add(nodea)
            nodea = nodea.next
        while nodeb != None:
            if nodeb in s:
                return nodeb
            nodeb = nodeb.next
        return None
```

## 易错点

- **别用 `val` 判等**：必须比较节点本身（`is` / 对象身份）。链表节点值可以重复。
- **要的是第一个交点，不是最后一个相同节点**：交点之后是**共享**的同一段内存，不是「值恰好相同」。用「找最后一个相同节点」的思路会得到 `c3`，错误。
- **返回值语义**：返回的是**节点对象**，不是下标或值。测试时要用 `result is expected_node` 判断。
- **无交点**：两个链表完全独立时，遍历 B 走到底返回 `None`。注意 `headA`/`headB` 本身为 `None` 的情况，本实现里 `while nodea != None` 会直接跳过，`nodeb in s` 中 `s` 为空 → 返回 `None`，行为正确。
- **不能修改链表结构**：题目明确要求保持原结构。双指针解法天然满足；哈希解法也不改动链表。

## 两种解法对比

| 解法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 哈希集合 | O(m+n) | O(m) | 直观好写，面试先说这个 |
| 双指针 | O(m+n) | **O(1)** | 更优，需要想清楚「路程相等」的论证 |

面试建议：先说哈希解法（能快速写出、讲清正确性），再补充双指针的 O(1) 优化 —— 展示思路递进。
