# 删除链表的倒数第 N 个结点 (Remove Nth Node From End of List)

> LeetCode 19 · 难度：中等 · 标签：链表、双指针

## 题目

给你一个链表，删除链表的**倒数第 `n` 个结点**，并且返回链表的头结点。

```
输入: head = [1,2,3,4,5], n = 2
输出: [1,2,3,5]

输入: head = [1], n = 1
输出: []

输入: head = [1,2], n = 1
输出: [1]
```

## 思路

### 思路一：先求长度，再删正向第几个（本仓库实现）

链表只能从头往后走，没法直接「倒数第 n 个」。最直观的做法是转成正向位置：

1. 第一遍遍历求出链表长度 `L`
2. 倒数第 `n` 个就是**正数第 `L - n + 1` 个**（1 基）
3. 第二遍走到这个位置，把它删掉

本仓库的代码就是这样：

```python
list_len = 0
list1 = head
while list1 != None:
    list1 = list1.next
    list_len += 1
target = list_len - n + 1
```

删除时需要**前驱节点**，所以代码维护了两个指针：

| 变量 | 实际含义 |
|------|----------|
| `last` | 待删除节点的**前驱**（初始为头节点） |
| `pre` | **待删除节点**本身（初始为 `head.next`） |
| `count` | `pre` 当前所在的正向位置（1 基） |

> 变量命名有点反直觉：`last` 不是「最后」，`pre` 也不是「前驱」。阅读时以上表为准；功能本身是正确的。

**删除头节点是特例**：当头节点就是目标（`target == 1`）时，没有前驱，直接返回 `head.next` 即可。

- 时间 O(L)（两遍遍历）
- 空间 O(1)

### 思路二：快慢指针（一遍遍历，更优）

不用先求长度。让快指针先走 `n + 1` 步，然后快慢指针同步前进；快指针走到 `None` 时，慢指针正好停在**待删除节点的前一个节点**。

```python
class Solution(object):
    def removeNthFromEnd(self, head, n):
        dummy = ListNode(0, head)   # 哑节点，统一处理删除头节点
        fast = slow = dummy
        for _ in range(n + 1):
            fast = fast.next
        while fast:
            fast = fast.next
            slow = slow.next
        slow.next = slow.next.next
        return dummy.next
```

**为什么是 `n + 1` 步？** 假设链表长度 `L`，目标节点是正数第 `L - n + 1` 个，它的前驱是第 `L - n` 个。让快指针先拉开 `n + 1` 个身位，当快指针到达 `None` 时，慢指针恰好走 `L - n` 步，停在前驱位置。

**哑节点的作用**：如果待删除的是头节点，普通写法需要单独判断；加了哑节点后，头节点也有了「前驱」，删除逻辑统一成一行。

- 时间 O(L)（一遍遍历）
- 空间 O(1)

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 两次遍历（本仓库） | O(L) | O(1) | 直观，需要特判头节点 |
| 快慢指针（哑节点） | O(L) | O(1) | **一遍遍历**，逻辑统一 |

## 代码

```python
class Solution(object):
    def removeNthFromEnd(self, head, n):
        """
        :type head: Optional[ListNode]
        :type n: int
        :rtype: Optional[ListNode]
        """
        list_len = 0
        list1 = head
        while list1 != None:
            list1 = list1.next
            list_len += 1
        target = list_len - n + 1
        last = head
        pre = last.next
        count = 2
        if target == 1:
            return head.next
        while count != target:
            pre = pre.next
            last = last.next
            count += 1
        last.next = pre.next
        return head
```

## 易错点

- **正数位置算错**：倒数第 `n` 个对应正数第 `L - n + 1` 个（1 基），不是 `L - n`。`n = 1` 时目标就是最后一个节点。
- **删除头节点没有前驱**：必须单独处理 `target == 1`，直接返回 `head.next`；否则访问 `last.next` 会出错或删错节点。快慢指针写法用哑节点统一处理。
- **要删除的是节点本身，不是它的后继**：`last.next = pre.next` 跳过 `pre`；不要写成 `pre = pre.next` 而忘了改链接。
- **`pre` 初始化时机**：代码在 `target == 1` 判断之前就写了 `pre = last.next`。当 `target > 1` 时，链表至少有两个节点，`head.next` 一定存在，所以安全；若约束不保证，应先判断。
- **`n` 超出链表长度**：题目保证 `1 <= n <= L`。若不保证，`target` 可能 ≤ 0，循环会走到 `None` 并报错，需要额外校验。
- **空链表**：题目保证至少一个节点；`n >= 1`，空链表不在约束内。
- **快慢指针的步数**：是 `n + 1` 步，不是 `n` 步；差一步会导致慢指针停在目标节点上，无法删除。
- **哑节点的返回值**：返回 `dummy.next`，不是 `dummy`。
- **变量命名**：`last` 实际是前驱、`pre` 实际是待删除节点，容易误读；自己写时建议用 `prev` / `cur` 或 `slow` / `fast`。
- **不要修改节点值**：本题要求删除节点（改指针），不是把值改成下一个节点的值。
