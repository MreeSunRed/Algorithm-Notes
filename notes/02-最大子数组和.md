# 最大子数组和 (Maximum Subarray)

> LeetCode 53 · 难度：中等 · 标签：数组、动态规划、分治

## 题目

给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

## 思路

### 暴力解

枚举左右端点 `(i, j)` 求和，或用前缀和优化到 O(n²)。

- 时间 O(n²)，空间 O(n)

### 优化：动态规划（Kadane 算法）

**定义状态**：设 `f(i)` 为「**以 `nums[i]` 结尾**」的连续子数组的最大和。

注意这个定义的关键 —— 它强制子数组**必须包含 `nums[i]` 作为最后一个元素**。这样定义的好处是：`f(i)` 只依赖 `f(i-1)`，状态转移非常干净。

**转移方程**：

```
f(i) = max(nums[i], f(i-1) + nums[i])
```

这个 `max` 的两种选择有清晰的直觉：

| 选择 | 含义 |
|------|------|
| `nums[i]` | 前面的累加和是**负的**，拖后腿 —— 不如从 `i` 重新开一段 |
| `f(i-1) + nums[i]` | 前面还有正贡献 —— 接上，继续延长 |

**最终答案**：`max(f(0), f(1), …, f(n-1))`。

这里有个常见的思维陷阱：答案不是 `f(n-1)`。`f(n-1)` 只是「以最后一个元素结尾」的最优解，而全局最优可能在中途某处结束。所以必须用一个变量**沿途记录最大值**。

### 空间优化

`f(i)` 只用到 `f(i-1)`，历史状态再无用处 → 用一个变量滚动即可，不需要开 O(n) 的数组。

代码里的角色对应：

- `tempmax` ↔ `f(i-1)`，滚动变量，每轮更新
- `maxnum` ↔ 全局最大值，沿途打擂台

## 复杂度

- **时间 O(n)**：一次遍历，每轮 O(1) 操作
- **空间 O(1)**：只用两个变量（未优化版本是 O(n)）

## 代码

```python
class Solution(object):
    def maxSubArray(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        maxnum = nums[0]
        tempmax = nums[0]
        for i in range(1, len(nums)):
            tempmax = max(nums[i], nums[i] + tempmax)
            maxnum = max(tempmax, maxnum)
        return maxnum
```

## 易错点

- **初始化不能用 0**：必须用 `nums[0]`。反例 `nums = [-2, -1, -3]`，正确答案是 `-1`（最大的单个元素）；若初始化成 0，会错误返回 `0`。
- **子数组要求连续**：不能「排序后把正数加起来」—— 那是**最大子序列和**，另一类问题。
- **不是返回子数组本身**：本题只要求返回「和」。若要求返回区间，需要额外记录起止下标。
- **`tempmax` 与 `maxnum` 的更新顺序**：先更新 `tempmax`（得到含 `nums[i]` 的最优），再用它去更新 `maxnum`。写反了会漏掉当前元素。
- **空数组**：本题保证 `1 <= nums.length`，无需处理。若面试中不保证，需在开头加 `if not nums: return 0`。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` | `6` | 子数组 `[4, -1, 2, 1]` |
| `[1]` | `1` | 单元素 |
| `[5, 4, -1, 7, 8]` | `23` | 整个数组 |
| `[-2, -1, -3]` | `-1` | **全负数** —— 最容易被初始化坑掉的用例 |
