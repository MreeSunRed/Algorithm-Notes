# 合并两个有序链表 (Merge Two Sorted Lists)

> LeetCode 21 · 难度：简单 · 标签：链表、递归、双指针

## 题目

将两个**升序**链表合并为一个新的**升序**链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

```
输入: l1 = [1,2,4], l2 = [1,3,4]
输出: [1,1,2,3,4,4]
```

## 思路

### 双指针 + 哑节点

两个链表已经有序，合并的方式和归并排序的「归并」一步完全相同：

1. 用 `p1`、`p2` 分别指向两个链表的当前节点
2. 比较 `p1.val` 和 `p2.val`，把较小的节点接到结果链表末尾，并让对应指针后移
3. 某个链表走完后，把另一个链表剩下的部分**整段接上**

**为什么要用哑节点（dummy head）？**

结果链表的第一个节点需要特殊处理：如果直接维护 `head`，每次插入都要判断「是不是第一个节点」，代码会很啰嗦。创建一个不存实际值的哑节点，让 `cur` 始终指向结果链表末尾，最后返回 `dummy.next` 即可。

本仓库的实现正是这个套路：

```python
res = ListNode()      # 哑节点
head = res            # 保存哑节点，最后返回 head.next
while list1 and list2:
    ...
    res = res.next
if list1: res.next = list1
if list2: res.next = list2
return head.next
```

**注意**：这里直接**拼接原链表节点**，没有创建新节点。这是允许的，也最省空间；如果要求不能修改原链表，则需要复制节点。

### 递归写法

递归的定义也很自然：

- 如果 `l1` 为空，返回 `l2`；如果 `l2` 为空，返回 `l1`
- 否则比较两个头节点，较小的那个作为结果头，它的 `next` 等于「剩下部分合并」的结果

```python
class Solution(object):
    def mergeTwoLists(self, list1, list2):
        if not list1:
            return list2
        if not list2:
            return list1
        if list1.val <= list2.val:
            list1.next = self.mergeTwoLists(list1.next, list2)
            return list1
        list2.next = self.mergeTwoLists(list1, list2.next)
        return list2
```

- 时间 O(m + n)，空间 O(m + n)（递归栈）
- 代码短，但链表很长时不如迭代稳妥

## 复杂度

| 写法 | 时间 | 空间 |
|------|:----:|:----:|
| 迭代（本仓库） | O(m + n) | **O(1)**（不计输出） |
| 递归 | O(m + n) | O(m + n) 递归栈 |

每个节点只被访问一次；迭代只用了几个指针。

## 代码

```python
# Definition for singly-linked list.
class ListNode(object):
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution(object):
    def mergeTwoLists(self, list1, list2):
        """
        :type list1: Optional[ListNode]
        :type list2: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        res = ListNode()
        head = res
        while list1 != None and list2 != None:
            if list1.val <= list2.val:
                res.next = list1
                list1 = list1.next
            else:
                res.next = list2
                list2 = list2.next
            res = res.next
        if list1 != None:
            res.next = list1
        if list2 != None:
            res.next = list2
        return head.next
```

## 易错点

- **忘记返回 `head.next`**：`head` 是哑节点，真正的结果从它的下一个节点开始。返回 `head` 会多出一个值为 0 的节点。
- **比较用 `<=` 还是 `<`**：用 `<=` 可以保持相等元素的原始相对顺序（稳定），推荐；用 `<` 结果也正确，但稳定性差一些。
- **剩余部分要整段接上**：某个链表先走完后，直接 `res.next = 剩余链表` 即可，不要再用循环逐个复制。
- **两个 `if` 的顺序**：循环结束时至多一个链表非空，两个独立 `if` 都能正确覆盖；写成 `if/elif` 也可以。
- **空链表**：两个都空时返回 `None`；一个为空时返回另一个，本实现天然支持。
- **修改了输入链表**：本实现直接拼接原节点，会改变原链表的结构（`next` 指针被重连）。若不允许修改输入，需要新建节点复制值。
- **哑节点的值**：`ListNode()` 默认 `val = 0`，这个 0 不会出现在结果里，不要把它当成真实数据。
- **递归版的终止条件**：必须先处理空链表，否则访问 `.val` 会报错。
- **`ListNode` 定义**：LeetCode 已内置；本仓库为了测试文件能独立运行保留了定义，提交时只需保留 `Solution`。

## 边界测试

| 输入 | 输出 | 说明 |
|------|------|------|
| `[1,2,4] + [1,3,4]` | `[1,1,2,3,4,4]` | 经典用例 |
