# 三数之和 (3Sum)

> LeetCode 15 · 难度：中等 · 标签：数组、双指针、排序

## 题目

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 `0` 且**不重复**的三元组。

注意：答案中不可以包含重复的三元组。

```
输入: nums = [-1,0,1,2,-1,-4]
输出: [[-1,-1,2],[-1,0,1]]

输入: nums = [0,1,1]
输出: []

输入: nums = [0,0,0]
输出: [[0,0,0]]
```

## 思路

### 暴力解

三重循环枚举所有 `(i, j, k)`，判断和是否为 0，最后用集合去重。

- 时间 O(n³)
- 需要处理大量重复结果

### 排序 + 固定一个数 + 双指针

这是本题的标准解法：

1. **先排序**：让数组有序，才能用双指针，也方便跳过重复值
2. 枚举第一个数 `nums[i]`
3. 在 `i` 右边用双指针 `left = i + 1`、`right = n - 1` 找两数之和等于 `-nums[i]`
4. `sum < 0` → `left++`；`sum > 0` → `right--`；`sum == 0` → 记录答案，并跳过左右两侧的重复值

```python
class Solution(object):
    def threeSum(self, nums):
        nums.sort()
        res = []
        n = len(nums)
        for i in range(n - 2):
            if nums[i] > 0:
                break                      # 最小的数都大于 0，后面不可能凑成 0
            if i > 0 and nums[i] == nums[i - 1]:
                continue                   # 跳过重复的第一个数
            left, right = i + 1, n - 1
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    res.append([nums[i], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
        return res
```

- 时间 O(n²)：外层 n 次，内层双指针 O(n)
- 空间 O(1)（不计排序和输出）

**双指针为什么能工作？** 固定 `nums[i]` 后，问题变成「有序数组中找两数之和等于目标值」，双指针从两端向中间收缩，和太小就左移、太大就右移，O(n) 完成。

### 本仓库实现：固定两端 + 哈希查第三个数

代码换了一个角度：

1. 排序，并用 `Counter` 统计每个值的出现次数
2. 外层固定左端点 `left`（只枚举 `nums[left] <= 0` 的位置）
3. 内层固定右端点 `right`，从右向左扫描
4. 第三个数 `target = -(nums[left] + nums[right])`，直接在哈希表里查是否存在
5. 用出现次数检查 `target` 是否有足够的副本（避免同一个下标被用两次）
6. 最后用 `set` 对三元组去重

**外层为什么只枚举 `nums[left] <= 0`？** 排序后，`nums[left]` 是三元组中最小的数；如果它都大于 0，三个正数之和不可能为 0。

**出现次数检查的作用**：假设 `target == nums[left]`（例如 `[-1,-1,2]`），需要至少两个 `-1`；若 `Counter` 显示只有一个，就不能构成三元组。`num_hash[target] < 2` 的判断正是为此。

**结尾去重**：`{tuple(x) for x in res}` 把每个三元组转成元组放进集合，天然去掉重复，再转回列表。结果顺序不重要。

- 时间 O(n²)：外层 O(n)，内层右指针 O(n)
- 空间 O(n)：`Counter` + 去重集合

**和标准写法相比**：本实现正确，但逻辑分支多、还要额外去重；标准双指针写法在找到答案时立即跳过重复值，不需要收尾去重，代码更短、常数更小，面试更推荐。

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 暴力三重循环 | O(n³) | O(n) | 去重麻烦，会超时 |
| 排序 + 双指针（推荐） | O(n²) | O(1) | 边找边跳过重复 |
| 本仓库（固定两端 + 哈希） | O(n²) | O(n) | 思路可行，但需要收尾去重 |

## 代码

```python
from collections import Counter


class Solution(object):
    def threeSum(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        nums = sorted(nums)
        num_hash = dict(Counter(nums))
        if len(num_hash) == 1:
            if nums[0] == 0:
                return [[0, 0, 0]]
        left = 0
        res = []
        while left < len(nums) - 2 and nums[left] <= 0:
            right = len(nums) - 1
            while left < right - 1 and nums[left] * nums[right] <= 0:
                target = -1 * (nums[left] + nums[right])
                if target in num_hash:
                    if target == nums[left] and num_hash[target] < 2:
                        right -= 1
                        continue
                    if target == nums[right] and num_hash[target] < 2:
                        right -= 1
                        continue
                    res.append(sorted([nums[left], target, nums[right]]))
                right -= 1
            left += 1

        return [list(x) for x in {tuple(x) for x in res}]
```

## 易错点

- **不排序**：双指针和「跳过重复值」都依赖有序数组。
- **重复三元组**：标准写法要在三个位置分别跳过重复：外层 `nums[i]`、双指针移动后的 `nums[left]` 和 `nums[right]`。本实现用集合收尾去重，能保证正确，但多了一次 O(n²) 的存集合操作。
- **同一个下标用两次**：例如 `[-1,-1,2]` 需要两个 `-1`。本实现用 `Counter` 计数检查；标准双指针天然保证 `left < right`，不会重复使用下标。
- **全零特判**：`[0,0,0]` 要返回 `[[0,0,0]]`；本实现用 `len(num_hash)==1` 且值为 0 来处理。标准双指针写法不需要特判。
- **外层边界**：只枚举 `nums[i] <= 0` 的位置；如果最小值已经大于 0，可以直接结束。
- **双指针移动方向**：和小于 0 移动左指针（增大和），和大于 0 移动右指针（减小和）；写反会死循环或漏解。
- **输出格式**：返回 `List[List[int]]`，不是元组列表；顺序任意。
- **空数组/长度不足 3**：返回 `[]`。本实现的 `len(num_hash)==1` 对空数组会 `nums[0]` 越界，但 LeetCode 保证 `3 <= nums.length`；工程代码应先判长度。
- **复杂度**：这道题不可能做到 O(n)，O(n²) 是标准复杂度；不要尝试用纯哈希做到 O(n)。
- **整数溢出**：Python 无溢出；其他语言注意 `-nums[i]` 的边界。
