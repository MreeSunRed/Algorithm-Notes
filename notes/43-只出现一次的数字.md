# 只出现一次的数字 (Single Number)

> LeetCode 136 · 难度：简单 · 标签：位运算、数组

## 题目

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

**要求：线性时间复杂度，且只使用常数额外空间。**

```
输入: nums = [2,2,1]
输出: 1

输入: nums = [4,1,2,1,2]
输出: 4

输入: nums = [1]
输出: 1
```

## 思路

### 常规解法及其代价

- **哈希表计数**：扫一遍统计出现次数，再找次数为 1 的键。时间 O(n)，空间 O(n)，不满足常数额外空间。
- **排序后相邻比较**：排序 O(n log n)，再找落单元素。时间不满足线性要求。
- **集合求和**：`2 * sum(set(nums)) - sum(nums)` 可以得到答案。思路巧妙，但 `set` 占 O(n) 空间，且元素为负数或很大时适用性受限。
- **数学性质**：`2 * sum(set) - sum` 本质利用「每个元素出现两次」，仍然需要额外集合。

### 本仓库实现：异或

异或运算有三条关键性质：

```
a ^ a = 0          # 相同为 0
a ^ 0 = a          # 与 0 异或保持不变
a ^ b ^ c = a ^ c ^ b   # 交换律、结合律
```

把数组中所有元素依次异或起来：

- 出现两次的元素会两两抵消成 `0`
- 只剩下出现一次的那个元素
- 运算顺序不影响结果，所以不需要排序或计数

以 `[4,1,2,1,2]` 为例：

| 步骤 | 当前元素 | res 变化 |
|:----:|:--------:|----------|
| 初始 | — | 0 |
| 1 | 4 | `0 ^ 4 = 4` |
| 2 | 1 | `4 ^ 1 = 5` |
| 3 | 2 | `5 ^ 2 = 7` |
| 4 | 1 | `7 ^ 1 = 6` |
| 5 | 2 | `6 ^ 2 = 4` |

最终 `res = 4`，正好是只出现一次的元素。

## 复杂度

- **时间 O(n)**：只遍历一次数组
- **空间 O(1)**：只用一个整数保存异或结果

## 代码

```python
class Solution(object):
    def singleNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        res = 0
        for i in nums:
            res = res ^ i
        return res
```

## 易错点

- **初始值写成 `nums[0]`**：虽然也能得到正确答案，但空数组会越界；从 `0` 开始更统一，也直接利用 `0 ^ x = x`。
- **把 `^` 当成幂运算**：Python 中 `^` 是按位异或，幂是 `**`。
- **用 `res ^= i` 之外还做多余判断**：本题不需要判断元素是否重复，异或天然抵消。
- **负数**：Python 整数按补码语义参与位运算，`-1 ^ -1 = 0`，结果正确；不需要特殊处理。
- **元素出现三次或多次**：异或只适用于「其余元素恰好出现两次」。出现三次应使用 137 题的按位统计或状态机。
- **有两个落单元素**：异或会得到两者的异或值，不能直接得出答案，需要用最低位的 `1` 分组（260 题）。
- **空数组**：LeetCode 保证 `1 <= nums.length`；本实现遇到空数组返回 `0`，属于约束外行为。
- **修改原数组**：异或写法不修改输入；若用排序或原地交换则要注意副作用。

## 边界测试

| 输入 | 输出 | 说明 |
|------|------|------|
| `[2,2,1]` | `1` | 经典用例，落单元素在末尾 |
| `[4,1,2,1,2]` | `4` | 落单元素在开头 |
| `[1]` | `1` | 只有一个元素 |
| `[1,1,2]` | `2` | 落单元素在末尾 |
| `[0,1,0]` | `1` | 包含 0，`0 ^ 0 = 0` |
| `[-1,-1,-2]` | `-2` | 负数异或 |
| `[10000,-10000,10000]` | `-10000` | 约束范围内的大值 |
| `[7,3,3,7,9]` | `9` | 多组重复交错出现，验证交换律 |
