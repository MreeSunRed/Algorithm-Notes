# 二进制位得分 (Binary Digit Score)

> LeetCode 4092 · 难度：简单 · 标签：位运算、数学

## 题目

给定两个整数 `a` 和 `b`，设：

- `s1` 为 `a` 的二进制表示中 **1 的个数**
- `s2` 为 `b` 的二进制表示中 **1 的个数**

得分规则：

- 如果 `s1 >= s2`，得分为 `s1 * s2`
- 否则，得分为 `s2 / s1`（**整数除法**，向下取整）

返回最终得分。

```
输入: a = 10, b = 12
输出: 4
解释: 10 = 1010₂，s1 = 2；12 = 1100₂，s2 = 2；s1 >= s2，得分 2 * 2 = 4。

输入: a = 14, b = 6
输出: 6
解释: 14 = 1110₂，s1 = 3；6 = 110₂，s2 = 2；得分 3 * 2 = 6。

输入: a = 5, b = 15
输出: 2
解释: 5 = 101₂，s1 = 2；15 = 1111₂，s2 = 4；s1 < s2，得分 4 / 2 = 2。
```

## 思路

这道题没有复杂的算法，核心只有两步：

1. **求两个数的 popcount**（二进制中 1 的个数）
2. **按规则计算**

### 求 popcount 的几种方式

**方式一：逐位除以 2（本仓库实现）**

不断对 2 取余、整除，余数为 1 就计数：

```python
while a != 0:
    if a % 2 == 1:
        s1 += 1
    a = int(a / 2)
```

- 时间 O(log a)，空间 O(1)
- 直观、不依赖语言特性，但 `int(a / 2)` 走了一次浮点除法

**方式二：右移**

```python
while a:
    s1 += a & 1
    a >>= 1
```

位运算版本更贴近「二进制」的语义，也避免了浮点转换。

**方式三：Python 内置 `bit_count()`**

```python
s1 = a.bit_count()
s2 = b.bit_count()
```

- Python 3.8+ 提供 `int.bit_count()`，底层直接数位，最快也最短
- 等价写法：`bin(a).count('1')`，但会先创建字符串，稍慢

### 按规则计算

```python
if s1 >= s2:
    return s1 * s2
return s2 // s1
```

题目要求的是**整数除法**，Python 中应使用 `//`；`int(s2 / s1)` 对正数结果相同，但会先转成浮点数，语义上不如 `//` 直接。

## 复杂度

| 写法 | 时间 | 空间 |
|------|:----:|:----:|
| 逐位除 2（本仓库） | O(log max(a, b)) | O(1) |
| 右移 | O(log max(a, b)) | O(1) |
| `bit_count()` | O(1)（字长固定） | O(1) |

本题约束很小（`1 <= a, b <= 100`），三种写法都绰绰有余。

## 代码

```python
class Solution(object):
    def calculateScore(self, a, b):
        """
        :type a: int
        :type b: int
        :rtype: int
        """
        s1 = 0
        s2 = 0
        while a != 0:
            if a % 2 == 1:
                s1 += 1
            a = int(a / 2)
        while b != 0:
            if b % 2 == 1:
                s2 += 1
            b = int(b / 2)
        if s1 >= s2:
            return s1 * s2
        return int(s2 / s1)
```

更简洁的写法：

```python
class Solution(object):
    def calculateScore(self, a, b):
        s1, s2 = a.bit_count(), b.bit_count()
        return s1 * s2 if s1 >= s2 else s2 // s1
```

## 易错点

- **整数除法写成真除法**：`s2 / s1` 在 Python 3 中返回 `float`（如 `4 / 2 = 2.0`），虽然本题能通过类型宽松的判题，但语义不对。用 `//` 或 `int(...)`。
- **除数可能为 0**：如果 `a = 0`，则 `s1 = 0`，走除法分支会触发 `ZeroDivisionError`。本题约束 `1 <= a, b <= 100`，`s1 >= 1`，所以安全；若扩展到 `a = 0`，需要特判。
- **用 `int(a / 2)` 而不是 `a // 2`**：前者经过浮点，数值很大时可能丢精度；位运算或整除更稳妥。
- **比较方向写反**：`s1 >= s2` 时返回乘积，只有 `s1 < s2` 才做除法。等号属于乘法分支。
- **除法结果的取整方式**：题目要求整数除法（向下取整），Python 的 `//` 对正数正好是向下取整。
- **修改了入参**：循环会把 `a`、`b` 变成 0；本题用完即弃，没有问题，但若后续还要用原值，应先拷贝。
- **`bit_count()` 的版本要求**：较老的 Python 没有这个方法，可退回 `bin(x).count('1')`。
- **popcount 不是「位数」**：`10 = 1010₂` 的二进制长度是 4，但 1 的个数是 2，别混淆。

## 边界测试

| 输入 | `s1` / `s2` | 输出 | 说明 |
|------|:-----------:|:----:|------|
| `a=10, b=12` | 2 / 2 | `4` | 相等，走乘法 |
| `a=14, b=6` | 3 / 2 | `6` | `s1 > s2` |
| `a=5, b=15` | 2 / 4 | `2` | `s1 < s2`，整数除法 |
| `a=1, b=1` | 1 / 1 | `1` | 最小值 |
| `a=1, b=2` | 1 / 1 | `1` | 相等 |
| `a=2, b=3` | 1 / 2 | `2` | `2 // 1` |
| `a=3, b=1` | 2 / 1 | `2` | 乘法分支 |
| `a=100, b=63` | 3 / 6 | `2` | `6 // 3` |
