# 合并 K 个升序链表 (Merge k Sorted Lists)

> LeetCode 23 · 难度：困难 · 标签：链表、分治、堆（优先队列）、归并排序

## 题目

给你一个链表数组，每个链表都已经按**升序**排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

```
输入: lists = [[1,4,5],[1,3,4],[2,6]]
输出: [1,1,2,3,4,4,5,6]

输入: lists = []
输出: []

输入: lists = [[]]
输出: []
```

## 思路

### 基础操作：合并两个有序链表

先复用 [21. 合并两个有序链表](27-合并两个有序链表.md) 的写法：用哑节点 + 双指针，每次把较小的节点接到结果尾部：

```python
def merge(self, l1, l2):
    dummy = ListNode()
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 or l2
    return dummy.next
```

本仓库的 `merge` 就是这个思路，额外在每次接上节点后写 `l3.next = None`，把原链表的后续指针暂时截断，最后再一次性接上剩余部分。功能正确。

### 逐个合并：为什么不够好

最直接的做法是维护一个结果链表，依次把第 1、2、…、k 个链表合并进去：

- 第 1 次合并 2 条链表，扫描约 `2N/k` 个节点
- 第 k 次合并时，结果链表已经有约 `N` 个节点，每次都要重复扫描前面的结果

总代价 O(Nk)。当 `k` 很大（例如 10⁴ 条链表）时会超时。

### 两两归并（本仓库实现，锦标赛式）

把链表两两配对合并，每轮链表数量大约减半：

```
[L1, L2, L3, L4, L5, L6, L7, L8]
→ [M12, M34, M56, M78]
→ [M1234, M5678]
→ [M1..8]
```

每一轮中，每个节点最多被扫描一次；一共约 `log k` 轮，所以总时间 **O(N log k)**。

本仓库的实现：

```python
while len(lists) > 1:
    i = 0
    while i < len(lists) and i + 1 < len(lists):
        mer_list = self.merge(lists[i], lists[i + 1])
        lists[i] = mer_list      # 合并结果放回第一个位置
        del lists[i + 1]         # 删除已经合并掉的第二个链表
        i += 1
return lists[0]
```

- `i += 1` 且删除元素后，下一对是原来的 `(2,3)`，不会重复合并
- `len(lists)` 每轮大约减半
- 直接在原 `lists` 上修改，额外空间 O(1)（不计输出）

### 另一种写法：最小堆

把每条链表的头节点放入小根堆，每次弹出最小值接到结果上，再把它的后继入堆：

```python
import heapq

class Solution(object):
    def mergeKLists(self, lists):
        heap = []
        for i, node in enumerate(lists):
            if node:
                heapq.heappush(heap, (node.val, i, node))
        dummy = ListNode()
        cur = dummy
        while heap:
            _, i, node = heapq.heappop(heap)
            cur.next = node
            cur = cur.next
            if node.next:
                heapq.heappush(heap, (node.next.val, i, node.next))
        return dummy.next
```

- 时间 O(N log k)，空间 O(k)
- **`i` 的作用**：`ListNode` 不能比较大小，堆元素写成 `(val, index, node)`，当值相等时用下标打破平局，避免 `TypeError`

### 分治递归写法

也可以用递归把区间一分为二，分别合并左右两半，再合并结果：

```python
def mergeKLists(self, lists):
    if not lists:
        return None
    def build(left, right):
        if left == right:
            return lists[left]
        mid = (left + right) // 2
        return self.merge(build(left, mid), build(mid + 1, right))
    return build(0, len(lists) - 1)
```

- 时间 O(N log k)，空间 O(log k) 递归栈
- 本仓库的迭代两两归并和它是同一个分治思路，只是把递归改成了循环

## 复杂度

设 `N` 为所有链表的节点总数，`k` 为链表条数。

| 写法 | 时间 | 额外空间 | 特点 |
|------|:----:|:--------:|------|
| 逐个合并 | O(Nk) | O(1) | 简单但慢，k 大时超时 |
| 两两归并（本仓库） | **O(N log k)** | O(1) | 原地复用节点，推荐 |
| 分治递归 | O(N log k) | O(log k) | 代码短，递归栈 |
| 最小堆 | O(N log k) | O(k) | 适合流式/动态场景 |

## 代码

```python
# Definition for singly-linked list.
class ListNode(object):
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution(object):

    def merge(self, l1, l2):
        if not l1:
            return l2
        if not l2:
            return l1
        l3 = ListNode()
        head = l3
        while l1 and l2:
            if l1.val >= l2.val:
                l3.next = l2
                l2 = l2.next
                l3 = l3.next
                l3.next = None
            else:
                l3.next = l1
                l1 = l1.next
                l3 = l3.next
                l3.next = None
        l3.next = l1 or l2
        head = head.next
        return head

    def mergeKLists(self, lists):
        """
        :type lists: List[Optional[ListNode]]
        :rtype: Optional[ListNode]
        """
        if lists == []:
            return None
        while len(lists) > 1:
            i = 0
            while i < len(lists) and i + 1 < len(lists):
                mer_list = self.merge(lists[i], lists[i + 1])
                lists[i] = mer_list
                del lists[i + 1]
                i += 1
        return lists[0]
```

## 易错点

- **逐个合并导致 O(Nk)**：每次都在一个越来越长的结果链表上重新扫描，链表数量大时会超时。要用两两归并或堆。
- **`lists` 为空 vs 只有一个空链表**：`lists = []` 返回 `None`；`lists = [[]]` 时 `lists[0]` 本身就是 `None`，也要返回 `None`。本实现两种都能处理。
- **空链表混在数组中**：`merge` 对 `None` 做了保护，传 `[None, [1,2]]` 也能正确返回 `[1,2]`。
- **堆元素不可比较**：`heapq` 在值相等时会比较第二个元素；如果直接放 `(val, node)`，`ListNode` 没有定义大小比较，会抛 `TypeError`。必须加一个可比较的下标或计数器。
- **原地修改了输入数组**：`del lists[i + 1]` 会改变调用方传入的列表。LeetCode 允许；若调用方后续还要用这个数组，应先拷贝。
- **归并配对错误**：合并后删除第二个元素并把结果放回第一个位置，`i` 要加 1 才能跳到下一对；否则会重复合并或漏掉链表。
- **`l3.next = None` 的作用**：本实现在接上节点后截断其原后继，避免旧指针残留；最后统一用 `l3.next = l1 or l2` 接上剩余部分。不要漏掉最后这一步。
- **相等值的顺序**：代码用 `>=`，相等时优先取第二条链表；题目只要求升序，不要求稳定，结果正确。
- **`ListNode` 定义**：LeetCode 已内置；本仓库为了测试能独立运行保留了定义，提交时只需保留 `Solution`。
- **`k = 0` 或 `k = 1`**：空数组返回 `None`；单条链表直接返回它本身，不需要走合并循环。
