# 最长连续序列 (Longest Consecutive Sequence)

> LeetCode 128 · 难度：中等 · 标签：数组、哈希表、并查集

## 题目

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

```
输入: nums = [100,4,200,1,3,2]
输出: 4
解释: 最长数字连续序列是 [1, 2, 3, 4]，长度为 4。

输入: nums = [0,3,7,2,5,8,4,6,0,1]
输出: 9
解释: 最长连续序列是 [0,1,2,3,4,5,6,7,8]，长度为 9。
```

## 思路

### 先看排序解法

排序后扫描一遍，统计相邻数字是否连续。时间 O(n log n)，不满足题目要求的 O(n)。

要降到 O(n)，必须在**不排序**的情况下快速判断「某个数在不在数组里」——这正是哈希表能做的。

### 哈希集合 + 只从序列起点开始数

把数组放进哈希集合（自动去重），然后遍历集合中的每个数 `k`：

- 如果 `k - 1` 也在集合里，说明 `k` 不是某段连续序列的起点，跳过
- 如果 `k - 1` 不在集合里，说明 `k` 是起点，于是从 `k` 开始不断检查 `k+1`、`k+2`……直到断开，得到这一段长度

**为什么必须只从起点开始数？**

假设数组是 `[1,2,3,4,...,n]`。如果对每个数都向后数一遍，总工作量是 `n + (n-1) + ... + 1 = O(n²)`。而只从「没有前驱」的数开始，每一段连续序列只会被完整遍历一次，总工作量 O(n)。

**不变量**：每段连续序列有且只有一个起点（`k-1` 不存在）。因此每个元素最多被访问一次。

### 本仓库实现：集合 + 起点计数

```python
num_set = set(nums)
max_len = 0
for k in num_set:
    if k - 1 not in num_set:
        count = 0
        while k + count in num_set:
            count += 1
        max_len = max(max_len, count)
return max_len
```

- `set(nums)` 一步完成去重和 O(1) 成员查询
- `if k - 1 not in num_set` 过滤出序列起点，避免从中间重复计数
- 从起点 `k` 开始，用 `k + count` 逐个向上数，直到断档

## 复杂度

- **时间 O(n)**（平均）：建集合 O(n)；每个数最多作为某段序列的一部分被检查一次，while 的总迭代次数不超过 n
- **空间 O(n)**：哈希集合需要存下所有不重复的元素

注意：哈希表的查询是**平均** O(1)，极端哈希冲突下理论最坏是 O(n²)，但实际判题中可视为 O(1)。

## 代码

```python
class Solution(object):
    def longestConsecutive(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        num_set = set(nums)
        max_len = 0
        for k in num_set:
            if k - 1 not in num_set:
                count = 0
                while k + count in num_set:
                    count += 1
                max_len = max(max_len, count)
        return max_len
```

## 易错点

- **对每个数都向后数**：这是最常见的超时原因。`[1,2,3,...,n]` 会退化成 O(n²)。必须先用 `k - 1 not in set` 过滤出起点。
- **用列表做成员判断**：`x in list` 是 O(n)，整体会退化到 O(n²)。必须用 `set` 或 `dict`。
- **忘记去重**：`[1,1,1]` 如果不去重，可能重复计数或死循环。`set(nums)` 天然去重。
- **空数组**：`nums = []` 时应返回 0。本实现中集合为空，`maxn` 保持 0，正确。
- **负数**：`-1, 0, 1` 也是连续序列，`k - 1` 的写法对负数同样成立，不需要特殊处理。
- **重复元素不影响答案**：`[1,2,0,1]` 的最长连续序列是 `[0,1,2]`，长度 3。
- **序列不要求在原数组中连续**：题目找的是**数值**连续，不是下标连续。`[100,4,200,1,3,2]` 的答案是 4，不是按原顺序找。
- **返回长度而不是序列**：题目只要求长度；若要返回具体序列，需要额外记录起点。
- **整数范围**：`k + count` 可能超出 32 位，Python 无溢出问题；其他语言需注意。
- **复杂度要求**：排序解法虽然简单，但是 O(n log n)，不满足题目的 O(n) 要求。
