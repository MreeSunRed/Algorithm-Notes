# 和为 K 的子数组 (Subarray Sum Equals K)

> LeetCode 560 · 难度：中等 · 标签：数组、哈希表、前缀和

## 题目

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的**连续子数组**的个数。

```
输入: nums = [1,1,1], k = 2
输出: 2
解释: [1,1] 出现两次（下标 [0,1] 和 [1,2]）。

输入: nums = [1,2,3], k = 3
输出: 2
解释: [1,2] 和 [3]。
```

## 思路

### 暴力解

枚举左右端点 `i`、`j`，计算 `nums[i..j]` 的和：

- 时间 O(n²)（边遍历边累加）或 O(n³)（每次重新求和）
- 空间 O(1)

### 为什么滑动窗口不行

一般的「子数组和」题可以用滑动窗口。但本题的 `nums` **可能包含负数**：

- 窗口右扩时和不一定增大，左缩时和不一定减小
- 「和太大就缩左边界」的单调性被破坏，窗口无法正确移动

所以本题不能用滑动窗口，需要用**前缀和 + 哈希表**。

### 前缀和转化

设 `pre[i] = nums[0] + nums[1] + ... + nums[i]`（`pre[-1] = 0`）。那么：

```
nums[i..j] 的和 = pre[j] - pre[i-1]
```

要求 `nums[i..j] 的和 == k`，等价于：

```
pre[j] - pre[i-1] == k
pre[i-1] == pre[j] - k
```

也就是说：**遍历到 `j` 时，只需要知道前面有多少个前缀和等于 `pre[j] - k`**。哈希表正好可以记录「每个前缀和出现了多少次」。

### 本仓库实现

```python
dic = {}                 # 前缀和 -> 出现次数
count = 0                # 当前前缀和
res = 0

for i in range(len(nums)):
    count += nums[i]
    target = count - k

    if target == 0:      # 空前缀（从下标 0 开始的子数组）
        res += 1
    res += dic.get(target, 0)

    dic[count] = dic.get(count, 0) + 1

return res
```

**`target == 0` 为什么单独处理？**

`target = 0` 表示需要一个「和为 0 的前缀」，即 `pre[i-1] = 0`。空前缀（一个元素都没选）的和就是 0，代表子数组从下标 0 开始。哈希表里没有这个空前缀，所以要单独补 1。

**等价的写法**：初始化 `dic = {0: 1}`，表示空前缀出现一次，然后去掉 `target == 0` 的特判：

```python
class Solution(object):
    def subarraySum(self, nums, k):
        from collections import defaultdict
        prefix = defaultdict(int)
        prefix[0] = 1
        count = res = 0
        for x in nums:
            count += x
            res += prefix[count - k]
            prefix[count] += 1
        return res
```

推荐这种写法：逻辑统一，不容易漏掉边界。

### 例子走一遍

`nums = [1,1,1]`，`k = 2`：

| i | 前缀和 | target | 命中 | res | 哈希表 |
|:-:|:------:|:------:|------|:---:|--------|
| 0 | 1 | -1 | 无 | 0 | `{1:1}` |
| 1 | 2 | 0 | 空前缀 +1 | 1 | `{1:1, 2:1}` |
| 2 | 3 | 1 | `{1:1}` +1 | 2 | `{1:1, 2:1, 3:1}` |

答案 2。

## 复杂度

- **时间 O(n)**（平均）：一次遍历，哈希表查询/插入均摊 O(1)
- **空间 O(n)**：哈希表最多存 n 个不同的前缀和

## 代码

```python
class Solution(object):
    def subarraySum(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: int
        """
        dic = dict()
        count = 0  # prefix
        res = 0
        for i in range(len(nums)):
            count += nums[i]
            target = count - k
            if target == 0:
                res += 1
            res += dic.get(target, 0)
            if count not in dic:
                dic[count] = 1
            else:
                dic[count] += 1
        return res
```

## 易错点

- **先插入当前前缀和再查询**：如果顺序反了，`target == count`（即 `k == 0`）时会把「当前元素自己构成的空子数组」也算进去，导致多计数。必须**先查询、后插入**。
- **忘记空前缀**：`target == 0` 代表子数组从下标 0 开始，必须补上。要么像本实现一样特判，要么初始化 `{0: 1}`。
- **哈希表只存「是否出现过」**：前缀和可能重复出现（例如数组含 0 或正负抵消），必须存**出现次数**，否则会漏掉多个子数组。
- **用滑动窗口**：数组含负数时窗口不单调，滑动窗口会漏解/错解。
- **把子数组和子序列混淆**：题目要求连续子数组，前缀和相减正好对应连续区间。
- **`k = 0`**：需要统计和恰好为 0 的子数组，`target == count`，前缀和重复计数必须正确。
- **空数组**：LeetCode 保证 `1 <= nums.length`；本实现遇到空数组返回 0，也正确。
- **返回的是个数**：不是最长长度，也不是具体子数组。
- **整数溢出**：Python 无溢出；其他语言前缀和可能超过 32 位，需用 64 位整数。
- **哈希表的键**：前缀和本身作为键，不要用下标或元素值。
