# 两两交换链表中的节点 (Swap Nodes in Pairs)

> LeetCode 24 · 难度：中等 · 标签：链表、递归

## 题目

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。

**要求：不能只修改节点内部的值，必须实际进行节点交换。**

```
输入: head = [1,2,3,4]
输出: [2,1,4,3]

输入: head = []
输出: []

输入: head = [1]
输出: [1]
```

## 思路

### 迭代写法：哑节点 + 三指针

在头节点前加一个哑节点 `dummy`，令 `prev` 指向「上一对交换后的尾节点」：

1. `first = prev.next`，`second = first.next`
2. `first.next = second.next`（把 first 接到下一对的开头）
3. `second.next = first`（second 移到 first 前面）
4. `prev.next = second`（上一对接到新的对头）
5. `prev = first`，继续处理下一对

```python
dummy = ListNode(0)
dummy.next = head
prev = dummy
while prev.next and prev.next.next:
    first = prev.next
    second = first.next
    first.next = second.next
    second.next = first
    prev.next = second
    prev = first
return dummy.next
```

- 时间 O(n)，空间 O(1)

### 本仓库实现：递归

```python
def swap(node):
    if node is None or node.next is None:
        return node
    second = node.next
    t = second.next
    second.next = node
    node.next = swap(t)
    return second
```

递归函数 `swap(node)` 的语义是：**交换以 `node` 开头的链表的前两个节点，返回交换后的头节点**。

- 若不足两个节点（`node` 为空或没有后继），无需交换，直接返回 `node`
- 否则 `second` 是这一对里的后一个节点，交换后它会成为新的头
- 先保存 `t = second.next`（下一对的开头），再把 `second.next` 指向 `node`
- `node.next` 递归处理剩下的部分，把结果接回来
- 最后返回 `second`

以 `[1,2,3,4]` 为例：

| 调用 | second | t | 交换后 | 返回 |
|------|:------:|:-:|--------|------|
| `swap(1)` | 2 | 3 | `2.next = 1`，`1.next = swap(3)` | 2 |
| `swap(3)` | 4 | None | `4.next = 3`，`3.next = None` | 4 |

把 `swap(3)` 的结果接回 `1.next`，最终得到 `2 → 1 → 4 → 3`。

**为什么必须先存 `t`？** `second.next = node` 会覆盖掉 `second` 原来的后继；如果先覆盖再取 `second.next`，后半段链表就丢了。

**奇数个节点怎么处理？** 最后一对凑不齐时，`node.next is None` 触发递归出口，原样返回最后一个节点，正好接在已交换部分后面。

## 复杂度

- **时间 O(n)**：每个节点只被访问常数次
- **空间 O(n)**：递归栈深度约为 n/2；迭代写法可以做到 O(1)

## 代码

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def swapPairs(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """

        def swap(node):
            if node == None or node.next == None:
                return node
            second = node.next
            t = second.next
            second.next = node
            node.next = swap(t)
            return second

        return swap(head)
```

## 易错点

- **覆盖 `second.next` 前没保存 `t`**：下一对链表的入口会丢失，导致结果只剩第一对。
- **返回 `node` 而不是 `second`**：交换后新的头是原来的第二个节点。
- **忘记处理不足两个节点的情况**：空链表、单节点、奇数长度的最后一节点都要原样返回。
- **只交换值不交换节点**：题目明确要求交换节点；只改 `val` 虽然可能通过部分用例，但不符合要求，遇到外部持有节点引用时也会出错。
- **哑节点的接法**：迭代写法中 `prev.next = second` 必须在新的一对内部指针调整完之后执行，否则会接错。
- **递归深度**：本题 `n <= 100`，约 50 层递归完全安全；若链表很长（超过默认递归上限 1000），应改用迭代。
- **空链表调用**：`swap(None)` 直接返回 `None`，不会访问 `.next`，安全。
- **指针环**：交换时 `second.next = node` 与 `node.next = ...` 的顺序不能反，否则可能形成自环。
