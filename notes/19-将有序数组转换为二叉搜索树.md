# 将有序数组转换为二叉搜索树 (Convert Sorted Array to Binary Search Tree)

> LeetCode 108 · 难度：简单 · 标签：树、二叉搜索树、数组、分治、二叉树

## 题目

给你一个整数数组 `nums`，其中元素已经按**升序**排列。请你将其转换为一棵**高度平衡**的二叉搜索树。

**高度平衡**二叉树是指：每个节点的左右两个子树的高度差的绝对值不超过 1。

```
输入: nums = [-10,-3,0,5,9]
输出: [0,-3,9,-10,null,5]   （也接受其他合法答案）
```

## 思路

### 两个关键性质

1. **BST 的中序遍历是升序序列**。题目给的正是升序数组，所以它可以直接当作某个 BST 的中序遍历结果。
2. **要高度平衡，根节点应当取中点**。中点把数组分成大小尽量相等的两半，左右子树节点数最多差 1，高度自然平衡。

这两点合起来，解法就出来了：

```
build(left, right):
    如果 left > right: 返回 None
    mid = (left + right) // 2
    根 = TreeNode(nums[mid])
    根的左子树 = build(left, mid - 1)
    根的右子树 = build(mid + 1, right)
    返回 根
```

这是一个典型的分治：**选根 → 递归建左子树 → 递归建右子树**。

### 为什么取中点就能保证平衡

设区间长度为 `n`：

- 左半段长度约 `n/2`，右半段长度也约 `n/2`
- 每层递归都把问题规模减半，树高为 O(log n)
- 任意节点的左右子树节点数相差不超过 1，高度差也不会超过 1

如果贪方便取 `left` 或 `right` 作为根，数组会退化成一条链（高度 O(n)），不满足题目要求。

### 偶数长度取哪个中点

`n` 为偶数时，中点有两个。本实现取**靠左的中点** `(left + right) // 2`。取靠右的中点 `(left + right + 1) // 2` 同样合法，只是生成的树形状不同。

LeetCode 对这道题是 **Special Judge**：只要返回的树满足 BST 且高度平衡，任何形状都接受。所以不要纠结「标准答案」长什么样。

## 复杂度

- **时间 O(n)**：每个元素恰好创建一个节点
- **空间 O(log n)**：递归栈深度等于平衡树的高度；返回的树本身占 O(n) 空间

如果改用数组切片 `nums[:mid]` / `nums[mid+1:]`，每层都会复制数组，时间退化到 O(n log n)、空间 O(n log n)。用**下标区间**是更优的写法。

## 代码

```python
class Solution(object):
    def sortedArrayToBST(self, nums):
        """
        :type nums: List[int]
        :rtype: Optional[TreeNode]
        """
        def ToBST(left, right):
            if left > right:
                return None
            half = (left + right) // 2
            root = TreeNode(val=nums[half])
            root.left = ToBST(left, half - 1)
            root.right = ToBST(half + 1, right)
            return root

        return ToBST(0, len(nums) - 1)
```

## 易错点

- **终止条件写成 `left >= right`**：这样会漏掉叶子节点（`left == right` 时本应创建一个节点），结果少建很多节点。正确条件是 `left > right`。
- **区间边界不一致**：本实现用**闭区间** `[left, right]`，所以左子树是 `[left, mid-1]`、右子树是 `[mid+1, right]`。如果混用半开区间，很容易多建或漏建。
- **用切片递归**：`ToBST(nums[:mid])` 写起来短，但每层复制数组，时间和空间都会变差。用下标传递。
- **取端点作为根**：`mid = left` 或 `mid = right` 会构造出链状 BST，违反高度平衡。
- **`int((left + right) / 2)` 的浮点问题**：小数据没问题，但语义上应使用整数除法 `//`，避免不必要的浮点转换。
- **空数组**：`ToBST(0, -1)` 中 `left > right` 成立，返回 `None`，正确。
- **`TreeNode` 的定义**：LeetCode 已内置 `TreeNode`。本仓库的题解会**构造**节点，因此文件里保留了定义、方便独立运行；提交到 LeetCode 时只需保留 `Solution` 类，避免与平台定义重复。
- **结果不唯一**：不要用「层序数组必须等于某个固定值」来测试，应验证中序序列等于原数组、且树高度平衡。
