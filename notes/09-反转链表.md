# 反转链表 (Reverse Linked List)

> LeetCode 206 · 难度：简单 · 标签：链表、递归

## 题目

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

```
输入: 1 → 2 → 3 → 4 → 5
输出: 5 → 4 → 3 → 2 → 1
```

## 思路

### 核心操作：把每根箭头掉头

反转链表不需要移动节点，只需要把每个节点的 `next` 指针从「指向后一个」改成「指向前一个」。

问题在于：改指针的同时，**不能弄丢后面的节点**。如果先把 `cur.next` 指向前面，就再也找不到原来的后继了。所以每一步都必须先把「下一步」保存在手里。

### 迭代：两个指针 + 一个暂存

标准的写法用三个角色：

- `prev`：已经反转好的那一段的头（初始为 `None`）
- `cur`：当前正在处理的节点
- `nxt`：暂存 `cur.next`，防止断链

每一步做四件事：

1. 记住 `cur.next`
2. 把 `cur.next` 指向 `prev`
3. `prev` 前移到 `cur`
4. `cur` 前移到刚才记住的 `nxt`

**不变量**：任意时刻，`prev` 指向「已反转前缀」的头，`cur` 指向「尚未处理的剩余部分」的头。循环直到 `cur` 为空，此时 `prev` 就是整个新链表的头。

### 本仓库的实现：用 `head` 兼任 `cur`

代码换了个角度，少用一个显式变量：

```python
tailA = None
while head != None:
    p = head          # p 是当前节点
    head = head.next  # 先前进，head 变成剩余部分的头
    p.next = tailA    # 再把当前节点接到已反转部分的头部
    tailA = p         # 已反转部分的头前移
return tailA
```

角色对应：

| 变量 | 含义 |
|------|------|
| `head` | 尚未处理的剩余链表 |
| `p` | 当前正在摘下的节点 |
| `tailA` | 已反转部分的头（相当于标准写法的 `prev`） |

**关键顺序**：`head = head.next` 必须在 `p.next = tailA` **之前**。先保存「回家的路」，再改指针；反过来写就断链了。

### 递归写法

递归的思路是「先反转后面的部分，再把自己接到末尾」：

```python
class Solution(object):
    def reverseList(self, head):
        if not head or not head.next:
            return head
        new_head = self.reverseList(head.next)
        head.next.next = head   # 让后继反过来指向自己
        head.next = None        # 断开原来的正向指针，避免成环
        return new_head
```

- 时间 O(n)，空间 O(n)（递归调用栈）
- 逻辑优美，但链表很长时有栈溢出风险，工程上更常用迭代

## 复杂度

| 写法 | 时间 | 空间 |
|------|:----:|:----:|
| 迭代（本仓库） | O(n) | **O(1)** |
| 递归 | O(n) | O(n) |

每个节点恰好被访问一次，迭代只用了三个指针变量。

## 代码

```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        tailA = None
        while head != None:
            p = head
            head = head.next
            p.next = tailA
            tailA = p
        return tailA
```

## 易错点

- **先改指针再保存后继**：`p.next = tailA` 之后再读 `head.next`，拿到的是已经改过的值，后半段会丢失。必须**先前进 `head`，再改 `p.next`**。
- **返回 `head` 而不是 `tailA`**：循环结束时 `head` 一定是 `None`，它只是「剩余部分的头」，不是答案。新链表的头是 `tailA`。
- **空链表**：`head = None` 时循环不执行，直接返回 `None`，本实现正确。
- **单节点**：`p.next = None`、`tailA = p`，返回该节点，正确。注意初始 `tailA = None` 正是为了让原头节点反转后指向空。
- **递归版忘记 `head.next = None`**：会让原头节点和第二个节点互相指向，形成环，遍历时死循环。递归返回的是 `new_head`，不是 `head`。
- **只改 `val` 不改指针**：某些变体允许交换值，但本题的标准解法是改指针；改值在节点不可变或存在外部引用时会出问题。
- **不要用 `head = head.next` 覆盖后再需要旧头**：本实现先用 `p` 接住当前节点，顺序不能颠倒。
