# 有效的括号 (Valid Parentheses)

> LeetCode 20 · 难度：简单 · 标签：字符串、栈

## 题目

给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用**相同类型**的右括号闭合
2. 左括号必须以**正确的顺序**闭合
3. 每个右括号都有一个对应的相同类型的左括号

```
输入: s = "()[]{}"   输出: true
输入: s = "([)]"     输出: false
输入: s = "{[]}"     输出: true
```

## 思路

### 暴力解

反复在字符串中寻找相邻的 `"()"`、`"[]"`、`"{}"` 并删除，直到无法再删；最后字符串为空则有效。

- 每一轮删除都要重建字符串，最坏 O(n²)
- 需要额外的字符串拷贝空间

这个解法是对的，但「反复扫描」的浪费很明显 —— 明明一次从左到右扫完就该能判断。

### 优化：栈

括号的合法性本质是**嵌套**：最后出现的左括号，必须最先被右括号闭合。这正是**后进先出**，天然对应栈。

一次遍历，规则只有两条：

| 遇到 | 动作 |
|------|------|
| 左括号 | 压栈 —— 它还没有被闭合 |
| 右括号 | 检查**栈顶**是否是它的同类左括号：是则弹出；否则无效 |
| 扫描结束 | 栈必须为空（没有残留的未闭合左括号） |

**为什么必须比较栈顶，而不是「栈里存在就行」？**

反例 `"([)]"`：扫描到 `')'` 时，栈里是 `['(', '[']`，确实「存在」一个 `'('`，但栈顶是 `'['`。若允许随便取一个配对，就会得出错误结论。**最近的未闭合左括号必须先闭合**，所以只能看栈顶。

**不变量**：扫描到任意位置时，栈里恰好是「当前所有尚未闭合的左括号」，且从栈底到栈顶就是它们在字符串中出现的顺序。

**为什么最后要判空？**

反例 `"((("`：全程没有右括号来触发 `else` 分支，循环顺利结束。只有检查栈为空，才能发现这些左括号没人闭合。

## 复杂度

- **时间 O(n)**：每个字符入栈/出栈至多一次，均为 O(1)
- **空间 O(n)**：最坏情况（全是左括号，如 `"((((("`）栈需要存下全部字符

## 代码

```python
class Solution(object):
    def isValid(self, s):
        """
        :type s: str
        :rtype: bool
        """
        stack = []
        if len(s) == 1:return False
        for i in s:
            if i == '(' or i == '{' or i == '[':stack.append(i)
            elif i == ')' and len(stack) != 0 and stack[-1] == '(':stack.pop()
            elif i == ']' and len(stack) != 0 and stack[-1] == '[':stack.pop()
            elif i == '}' and len(stack) != 0 and stack[-1] == '{':stack.pop()
            else:return False
        if len(stack) != 0:return False
        return True
```

## 易错点

- **栈空时遇到右括号**：`s = ")"`，此时没有栈顶可看。本实现用 `len(stack) != 0` 拦住，走 `else` 返回 `False`。若漏掉这个判断，`stack[-1]` 会抛 `IndexError`。
- **结束时忘了判空**：`s = "(("` 会一路循环到底并错误返回 `True`。别忘了最后那一步 `len(stack) != 0 → False`。
- **只数括号个数是不够的**：`"([)]"` 里左右括号数量完全相等，但顺序非法。**顺序信息**只有栈能记住。
- **`len(s) == 1` 的提前返回**：对 `"("` 和 `")"` 都能正确返回 `False`，属于短路优化，但不是必需的 —— 栈的逻辑本身也能处理。注意空串 `""` 在本实现里会返回 `True`（循环不执行、栈为空），而 LeetCode 保证 `1 <= s.length`，无需处理。
- **把左括号的判断写成 `else` 分支**：输入已保证只含六种括号，但若改成 `if i in '([{':` 会更紧凑；否则必须显式枚举，避免把未知字符误判为左括号。

## 更紧凑的写法

把「右括号 → 对应左括号」放进字典，四个分支可以合并成两个：

```python
class Solution(object):
    def isValid(self, s):
        pairs = {')': '(', ']': '[', '}': '{'}
        stack = []
        for ch in s:
            if ch in pairs:
                if not stack or stack[-1] != pairs[ch]:
                    return False
                stack.pop()
            else:
                stack.append(ch)
        return not stack
```

`not stack` 同时处理了「栈空」和「扫描结束」，是这道题最惯用的写法。
