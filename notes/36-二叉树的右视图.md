# 二叉树的右视图 (Binary Tree Right Side View)

> LeetCode 199 · 难度：中等 · 标签：树、深度优先搜索、广度优先搜索

## 题目

给定一个二叉树的根节点 `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

```
输入: root = [1,2,3,null,5,null,4]
输出: [1,3,4]

      1            <- 看到 1
     / \
    2   3          <- 看到 3（2 被 3 挡住）
     \   \
      5   4        <- 看到 4（5 被 4 挡住）
```

## 思路

### 问题转化：每一层只保留最右边的节点

「站在右侧看」本质上是：**每个深度上只取最右侧的那个节点**。所以问题可以重新表述为：

> 对树的每一层，返回该层最后一个节点（最右节点）的值。

这样就把「视角」问题变成了「按层取最右」问题，可以用 DFS 也可以用 BFS。

### 本仓库实现：右优先 DFS + 深度标记

深度优先遍历时**先走右子树、再走左子树**。这样同一深度上第一个被访问的节点，一定就是该层最右侧的节点。用 `h` 记录当前深度（根为 1），用 `self.res` 收集结果：

```python
def dsf(root, h):
    if root == None:
        return
    if h > len(self.res):        # 这一层还没有被记录过
        self.res.append(root.val)
    dsf(root.right, h + 1)       # 先右
    dsf(root.left, h + 1)        # 后左
```

**为什么 `h > len(self.res)` 能判断「第一次到达第 h 层」？**

`res` 的长度恰好等于「已经发现过的最大层数」：

- 第一次到达第 `h` 层时，前面的 `h - 1` 层都已经记录过，`len(res) = h - 1`，条件成立，追加该节点。
- 之后同一层再被访问（来自左子树），`len(res) >= h`，条件不成立，不会重复记录。

用 `h == len(res)` 在「层数只能逐级 +1」的前提下也能工作，但 `>` 更稳健，不依赖这个隐含前提。

**为什么右优先 DFS 得到的一定是最右节点？**

对每个深度归纳：第 1 层只有根；到达第 `d` 层时，右优先的顺序保证右子树的节点一定先于左子树节点被访问。因此第 `d` 层第一个被访问的节点，就是该层最靠右的节点。即使右子树比左子树浅（例如 `[1,2,3,4]` 第 3 层只有左子树的节点），左子树节点仍然会是这一层**第一个**被访问的节点，照样能被正确记录。

### 另一种写法：BFS 层序，每层取最后一个

最符合直觉的写法：标准层序遍历，每层处理完后取该层最后一个元素。

```python
from collections import deque

class Solution(object):
    def rightSideView(self, root):
        if not root:
            return []
        res = []
        q = deque([root])
        while q:
            level = []
            for _ in range(len(q)):      # 快照当前层长度
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level[-1])        # 只保留最右
        return res
```

- 时间 O(n)，空间 O(w)（`w` 为最大宽度）
- 逻辑直白，但需要额外保存每层全部节点（也可以只记录每层最后一个值，省掉 `level` 列表）

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 右优先 DFS（本仓库） | O(n) | O(H) 递归栈 | 一次遍历，不需要队列 |
| BFS 层序 | O(n) | O(w) 队列 | 直观，按层取最后 |
| BFS 只记每层最后一个 | O(n) | O(w) | 省掉 level 列表 |

- `n` 为节点数，`H` 为树高，`w` 为最大宽度
- 结果数组本身占 O(H)，不计入额外空间

## 代码

```python
class Solution(object):
    def rightSideView(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: List[int]
        """
        self.res = []

        def dsf(root, h):
            if root == None:
                return
            if h > len(self.res):
                self.res.append(root.val)
            dsf(root.right, h + 1)
            dsf(root.left, h + 1)

        dsf(root, 1)
        return self.res
```

## 易错点

- **先左后右**：递归顺序反了，记录下来的就是每一层最**左**的节点，变成左视图。必须 `right` 在前。
- **判断条件写成 `>=`**：`if h >= len(self.res)` 对同层的第二个节点（`h = 1, len(res) = 1`）也成立，会把整棵树的节点全追加进去。必须是 `>`（或 `==`）。
- **`h` 与 `len(res)` 的基准不一致**：`h` 从 1 开始，`res` 从空（长度 0）开始，两者配合才是「新的一层」；如果把 `h` 从 0 开始，判断要跟着改成 `h == len(res)`。
- **忘记初始化 `self.res`**：同一个 `Solution` 实例多次调用会残留上一次的结果。本实现每次调用都重新赋值为 `[]`。
- **右子树比左子树浅**：例如 `[1,2,3,4]`，第 3 层只有左子树的 4。右优先 DFS 仍会访问到它，并且因为该层还没被记录，结果正确；不要想当然地认为「只走右孩子」。
- **空树**：`root = null` 时返回 `[]`。`dsf(None, 1)` 直接返回，`res` 保持空列表。
- **递归深度**：退化成链时递归深度 O(n)，节点数很大时可能触发 Python 递归上限；BFS 写法没有这个问题。
- **返回类型**：返回 `List[int]`，是节点值列表，不是节点列表。
- **把结果写成二维数组**：本题只返回每层最右的一个值，不是层序遍历的完整结果。
