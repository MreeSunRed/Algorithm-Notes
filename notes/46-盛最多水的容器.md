# 盛最多水的容器 (Container With Most Water)

> LeetCode 11 · 难度：中等 · 标签：数组、双指针、贪心

## 题目

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

**说明**：不能倾斜容器。

```
输入: height = [1,8,6,2,5,4,8,3,7]
输出: 49
解释: 选择第 2 条线（height[1]=8）和第 9 条线（height[8]=7），
      容器高度为 min(8,7)=7，宽度为 8-1=7，面积 49。
```

## 思路

### 面积公式

任选两条线 `i < j`，容器面积：

```
area = min(height[i], height[j]) × (j - i)
```

- **高度**由较短的那条线决定（水会从矮的一侧溢出）
- **宽度**是两条线的下标差，不是线的数量

目标是最大化这个面积。

### 暴力解

枚举所有 `(i, j)` 组合，计算面积取最大：

- 时间 O(n²)，空间 O(1)
- 数据量大时会超时

### 标准解法：双指针（O(n)）

从数组两端开始：

```python
left, right = 0, len(height) - 1
while left < right:
    area = min(height[left], height[right]) * (right - left)
    best = max(best, area)
    if height[left] < height[right]:
        left += 1
    else:
        right -= 1
```

**为什么移动较短的那一侧？**

假设 `height[left] < height[right]`，当前面积受 `height[left]` 限制。如果移动较高的 `right`：

- 宽度一定减小
- 高度仍然受 `height[left]` 限制（新的 `height[right]` 即使更高也没用，若变矮则高度更小）

所以移动较高的一侧**不可能得到更大的面积**，可以安全排除。反之，移动较矮的一侧，虽然宽度减小，但可能遇到更高的线，让高度提升，从而得到更大面积。

每一步都排除一个不可能的候选，总共 O(n) 步。

### 本仓库实现：按高度阈值找最宽端点

代码先取出所有不同的高度，从高到低枚举阈值 `i`：

1. 找到最左边 `height[left] >= i` 的位置
2. 找到最右边 `height[right] >= i` 的位置
3. 面积 `i × (right - left)` 一定可以构成（两条线都不低于 `i`）
4. 对所有阈值取最大

**为什么正确？** 对于固定高度 `i`，能构成高度为 `i` 的容器中，宽度最大的就是「最左和最右的 ≥ i 的位置」。任何更窄的区间，高度相同、宽度更小，不可能更优。所以枚举所有阈值就能覆盖最优解。

**代价**：每个不同高度都要从两端各扫一遍，最坏情况（所有高度都不同）会退化到 O(n²)。LeetCode 的数据规模可达 `10^5`，这个写法可能超时；标准双指针是 O(n)。

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 暴力枚举 | O(n²) | O(1) | 直观，会超时 |
| 双指针（推荐） | **O(n)** | O(1) | 每步排除一个候选 |
| 本仓库（高度阈值） | O(n · 不同高度数)，最坏 O(n²) | O(n) | 思路正确，但大数据会慢 |

## 代码

```python
class Solution(object):
    def maxArea(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        h_list = sorted(set(height))
        area_max = 0
        for i in h_list[::-1]:
            left = 0
            while height[left] < i:
                left += 1
            right = len(height) - 1
            while height[right] < i:
                right -= 1
            area_max = max(area_max, i * (right - left))
        return area_max
```

## 易错点

- **宽度算成线的数量**：宽度是下标差 `right - left`，不是 `right - left + 1`。
- **高度用错**：容器高度是 `min(height[left], height[right])`，不是高度之和，也不是平均值。
- **双指针移动较高的一侧**：这样会漏掉最优解。必须移动较矮的一侧，原因见上面的证明。
- **相等时移动哪边**：两侧相等时移动任意一边都可以，不会漏解（另一边一定也能在后续被考虑到）。
- **高度阈值写法的复杂度**：代码本身正确，但每个不同高度都要扫描数组，最坏 O(n²)。数据量大时应改用双指针。
- **内部更矮的线不影响结果**：容器只由两条边界线决定，中间的线高低无关；不要误以为必须找「连续递增」的区间。
- **`left` / `right` 扫描越界**：本实现的阈值 `i` 来自 `set(height)`，所以一定存在 `height >= i` 的位置，两个 while 都不会越界。
- **空数组/单条线**：题目要求至少两条线（`n >= 2`）。单条线无法构成容器，返回 0；本实现若遇到空数组会越界，需按约束处理。
- **面积范围**：`10^5 × 10^4 = 10^9`，Python 无溢出；其他语言注意用 64 位整数。
