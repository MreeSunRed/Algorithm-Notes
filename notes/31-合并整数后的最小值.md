# 合并整数后的最小值 (Minimum Value of Merged Integers)

> LeetCode 4097 · 难度：简单 · 标签：数组、字符串、模拟

## 题目

给定一个整数数组 `nums`，将数组中的元素按**固定配对**两两合并：

- `nums[0]` 与 `nums[1]` 合并
- `nums[2]` 与 `nums[3]` 合并
- 以此类推……

合并的方式是把两个整数的**十进制表示直接拼接**成一个新整数。返回所有合并结果中的**最小值**。

```
输入: nums = [70,41,91,11]
输出: 7041
解释:
  (70, 41) → 7041
  (91, 11) → 9111
  最小值是 7041。
```

## 思路

这道题没有复杂的算法，按题意模拟即可：

1. 从下标 0 开始，每次取 `nums[i]` 和 `nums[i+1]`
2. 把两个数转成字符串后拼接，再转回整数
3. 用变量记录出现过的最小值
4. `i += 2`，处理下一对

**关键点：配对是固定不重叠的。** 不是「任意相邻两个数都可以合并」，而是 `(0,1)`、`(2,3)`……每一对数只和它的搭档合并。因此下标必须每次前进 **2**，而不是 1。

### 为什么用字符串拼接

「把 70 和 41 合并成 7041」在数学上等价于：

```
70 × 10² + 41 = 7041
```

其中 `2` 是第二个数的位数。用字符串拼接 `str(a) + str(b)` 再 `int(...)`，可以不用关心位数，代码最短；代价是会创建临时字符串。

如果不允许字符串操作，可以先求位数再算：

```python
digits = len(str(b))          # 仍然用了 str
merged = a * (10 ** digits) + b
```

在本题「每个数最多四位」的规模下，两种写法都很快。

### 本仓库实现

```python
macsh = sys.maxsize
i = 0
while i < len(nums) - 1:
    a = str(nums[i])
    b = str(nums[i + 1])
    c = int(a + b)
    i += 2
    macsh = min(macsh, c)
return macsh
```

变量 `macsh` 用来保存当前最小值，初值取 `sys.maxsize`（相当于正无穷）。只要至少存在一对，它就会被更新。

## 复杂度

- **时间 O(n · d)**：每个数只参与一次拼接，`d` 是数字位数；本题 `d ≤ 4`，可视为 O(n)
- **空间 O(1)**：只用了常数个临时变量和字符串

## 代码

```python
import sys


class Solution(object):
    def minMergedInteger(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        macsh = sys.maxsize
        i = 0
        while i < len(nums) - 1:
            a = str(nums[i])
            b = str(nums[i + 1])
            c = int(a + b)
            i += 2
            macsh = min(macsh, c)
        return macsh
```

更短的写法：

```python
class Solution(object):
    def minMergedInteger(self, nums):
        return min(int(str(nums[i]) + str(nums[i + 1]))
                   for i in range(0, len(nums), 2))
```

## 易错点

- **步长写成 1（最常见的错误）**：如果写成 `i += 1`，会把 `(1,2)` 这类题目并不存在的配对也算进去。例如 `[70,41,91,11]` 会错误地得到 `4191`（41 和 91 拼接），而正确答案是 `7041`。
- **先转 `int` 再拼接**：`int(a) + int(b)` 是加法，不是拼接；必须先 `str()`。
- **忽略前导零**：`[1, 0]` 拼接成 `"10"`，结果是 10；`[0, 0]` 得到 `"00"`，`int` 后是 0。题目按拼接语义处理，不要试图保留前导零。
- **数组长度为奇数**：本实现的条件 `i < len(nums) - 1` 会忽略最后一个落单的元素。按题意数组长度应为偶数；如果题目允许奇数，需要先确认落单元素如何处理。
- **空数组或只有一个元素**：循环不执行，返回 `sys.maxsize`，显然不是合理答案。题目保证至少有一对元素；工程代码应加保护。
- **负数**：`str(-1) + str(2)` 得到 `"-12"`，`int` 后是 -12，语义会和「拼接」的直觉不一致。本题数值为正整数，无需处理。
- **`sys.maxsize` 溢出问题**：Python 不会溢出；其他语言用 `INT_MAX` 作为初值即可。
- **结果范围**：两个最多四位的数拼起来最多八位，Python 整数无压力；C++/Java 需要确认是否在 32 位范围内。

## 边界测试

| 输入 | 合并结果 | 输出 | 说明 |
|------|----------|:----:|------|
| `[70,41,91,11]` | 7041, 9111 | `7041` | 经典用例，抓步长错误 |
| `[10,2,30,4]` | 102, 304 | `102` | 多位数拼接 |
| `[1,23,4,56]` | 123, 456 | `123` | 位数不同 |
