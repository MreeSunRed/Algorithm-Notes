# 接雨水 (Trapping Rain Water)

> LeetCode 42 · 难度：困难 · 标签：数组、双指针、单调栈、动态规划

## 题目

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

```
输入: height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出: 6

输入: height = [4,2,0,3,2,5]
输出: 9
```

## 思路

### 每个位置能接多少水

对于下标 `i`，它上方能积的水取决于**左右两侧最高柱子的较小值**：

```
water[i] = max(0, min(left_max[i], right_max[i]) - height[i])
```

- `left_max[i]`：`i` 左边（含 `i`）的最高柱子
- `right_max[i]`：`i` 右边（含 `i`）的最高柱子
- 水面高度不可能超过较矮的那一侧，超过就会溢出去

所有位置的水量相加就是答案。不同解法的区别，只在于**如何高效地得到 `left_max` / `right_max`**。

### 思路一：前后缀最大值（DP）

先从左往右预处理 `left_max`，再从右往左预处理 `right_max`，最后逐位置计算水量：

```python
class Solution(object):
    def trap(self, height):
        n = len(height)
        if n == 0:
            return 0
        left_max = [0] * n
        right_max = [0] * n
        left_max[0] = height[0]
        for i in range(1, n):
            left_max[i] = max(left_max[i - 1], height[i])
        right_max[-1] = height[-1]
        for i in range(n - 2, -1, -1):
            right_max[i] = max(right_max[i + 1], height[i])
        return sum(min(left_max[i], right_max[i]) - height[i] for i in range(n))
```

- 时间 O(n)，空间 O(n)

### 思路二：双指针（O(1) 空间，推荐）

不需要完整数组，只要维护两个指针和两侧当前的最大值：

```python
class Solution(object):
    def trap(self, height):
        left, right = 0, len(height) - 1
        left_max = right_max = 0
        water = 0
        while left < right:
            if height[left] < height[right]:
                left_max = max(left_max, height[left])
                water += left_max - height[left]
                left += 1
            else:
                right_max = max(right_max, height[right])
                water += right_max - height[right]
                right -= 1
        return water
```

**为什么可以只更新一侧？**

当 `height[left] < height[right]` 时，右侧存在一根高度为 `height[right]` 的柱子，所以右侧真实的最大值 `right_max >= height[right] > height[left]`。此时 `min(left_max, right_max)` 一定由左侧决定，`i` 处的水量只取决于 `left_max`，可以安全结算并右移左指针。反之同理。

- 时间 O(n)，空间 **O(1)**

### 思路三：单调栈（本仓库实现）

栈里存**下标**，对应的高度从栈底到栈顶**非递增**。

当遇到一个高度 `height[i]` 大于等于栈顶高度时，说明栈顶这根柱子成为了某个「低洼」的底部：

1. 弹出栈顶 `bottom`
2. 弹出后如果栈为空，说明左边没有更高的柱子挡水，这一层无法积水，`break`
3. 否则新的栈顶 `left` 就是左墙，当前 `i` 是右墙
4. 这一层的水量：

```
高度 = min(height[left], height[i]) - height[bottom]
宽度 = i - left - 1
```

5. 重复弹出，直到栈顶高度大于当前高度，再把 `i` 压栈

**为什么宽度是 `i - left - 1`？** `left` 和 `i` 是两侧墙的下标，中间夹着的柱子宽度是 `i - left - 1`。

以 `[2,1,0,2]` 为例：

| 步骤 | 栈（下标） | 积水 |
|------|-----------|------|
| 处理 0（高度 2） | `[0]` | 0 |
| 处理 1（高度 1） | `[0,1]` | 0 |
| 处理 2（高度 0） | `[0,1,2]` | 0 |
| 处理 3（高度 2） | 弹 2：左墙 1，水位 `min(1,2)-0=1`，宽 1 → +1 | 1 |
| 继续弹 | 弹 1：左墙 0，水位 `min(2,2)-1=1`，宽 `3-0-1=2` → +2 | 3 |
| 弹 0 | 栈为空，`break` | 3 |

答案 3，符合预期。

**三种解法的取舍**：

| 解法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 前后缀最大值 | O(n) | O(n) | 最容易理解，先写这个 |
| 双指针 | O(n) | **O(1)** | 最优，面试首选 |
| 单调栈（本仓库） | O(n) | O(n) | 按「层」计算，适合练习单调栈 |

## 复杂度

- **时间 O(n)**：每个下标最多入栈、出栈各一次；双指针每个位置访问一次
- **空间**：栈解法 O(n)，双指针 O(1)，前后缀 O(n)

## 代码

```python
class Solution(object):
    def trap(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        stack_height = []
        rain = 0
        for i, v in enumerate(height):
            while stack_height and height[stack_height[-1]] <= height[i]:
                bottom = stack_height.pop()
                if not stack_height:
                    break

                rain += (
                    (min(height[stack_height[-1]], height[i]) - height[bottom])
                    * (i - stack_height[-1] - 1)
                )
            stack_height.append(i)

        return rain
```

## 易错点

- **弹出后忘记判空**：`bottom` 出栈后如果栈空，说明左侧没有更高的墙，这一层不能积水，必须 `break`；否则 `stack_height[-1]` 会越界。
- **宽度公式差一**：宽度是 `i - left - 1`，其中 `left` 是弹出后的新栈顶；不是 `i - left`，也不是 `i - bottom`。
- **高度公式用错**：这一层的水面高度是 `min(height[left], height[i])`，底部是 `height[bottom]`，两者相减；不要拿 `bottom` 两侧的任意高度直接相加。
- **比较用 `<=` 还是 `<`**：本实现用 `<=`，遇到等高柱也会弹出（这一层水量为 0），随后继续处理；两种写法都可以正确，但要保证栈的单调性和宽度计算自洽。
- **栈里存高度而不是下标**：计算宽度必须用下标；高度通过 `height[idx]` 取。
- **先更新最大值还是先加水**：双指针写法中先 `max` 更新再累加 `max - height[i]`；顺序反了在首次遇到更高柱时会算少。
- **双指针移动方向**：移动较矮的一侧，不是较高的一侧；移动较高侧会漏掉最优解。
- **空数组/单柱**：返回 0。上述三种解法都能正确处理（双指针/栈在 n < 2 时不进入循环）。
- **单调不增/不降的数组**：接不到水，答案应为 0；可以用这两个用例快速自查。
- **整数溢出**：Python 无溢出；其他语言注意累加结果可能超过 32 位。
