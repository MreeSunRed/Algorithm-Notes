# 移动零 (Move Zeroes)

> LeetCode 283 · 难度：简单 · 标签：数组、双指针

## 题目

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的**相对顺序**。

**要求原地操作**，不要返回新数组。

```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]

输入: nums = [0]
输出: [0]
```

## 思路

### 核心约束

- 所有 0 移到末尾
- **非零元素的相对顺序不能变**：`[1,3,12]` 必须保持这个顺序，不能变成 `[12,1,3]`
- 原地修改，额外空间 O(1)

### 标准写法：双指针交换

用一个 `write` 指针表示「下一个非零元素应该放的位置」，用 `read` 遍历数组：

- `nums[read] != 0` 时，把它和 `nums[write]` 交换，`write` 前进
- `nums[read] == 0` 时跳过

```python
class Solution(object):
    def moveZeroes(self, nums):
        write = 0
        for read in range(len(nums)):
            if nums[read] != 0:
                nums[write], nums[read] = nums[read], nums[write]
                write += 1
```

**为什么能保持相对顺序？** `read` 从左到右扫描，非零元素被依次放到 `write` 指向的位置；`write` 只会单调前进，所以先出现的非零元素一定先被放置。

**为什么能自动把零移到末尾？** 每次交换都把 `write` 位置的零换到了 `read` 位置；随着 `read` 往后走，零被逐步「赶」到数组后部。循环结束时，`[0, write)` 全是非零元素，`[write, n)` 全是零。

- 时间 O(n)，空间 O(1)

### 另一种写法：先覆盖非零，再补零

```python
write = 0
for x in nums:
    if x != 0:
        nums[write] = x
        write += 1
for i in range(write, len(nums)):
    nums[i] = 0
```

- 第一遍把所有非零元素按顺序写到前面
- 第二遍把剩余位置全部置 0
- 同样是 O(n) / O(1)，但需要两趟扫描

### 本仓库实现：定位零与「零后面的第一个非零」交换

代码用了两个指针：

- `first0`：从左往右找**第一个 0**
- `after0`：找「前一个位置是 0、当前位置非 0」的位置，也就是**零区间后面的第一个非零元素**

找到后交换二者，再重复。每轮交换都会把一个非零元素放到前面的零位上，同时把一个零换到后面。

以 `[0,1,0,3,12]` 为例：

| 轮次 | 交换 | 数组 |
|:----:|------|------|
| 1 | `nums[0]` ↔ `nums[1]` | `[1,0,0,3,12]` |
| 2 | `nums[1]` ↔ `nums[3]` | `[1,3,0,0,12]` |
| 3 | `nums[2]` ↔ `nums[4]` | `[1,3,12,0,0]` |

`first0` 和 `after0` 都只向右移动，不会回退，因此总时间 O(n)。

**它和标准写法的关系**：本质相同，都是「用后面的非零元素填补前面的零位」。只是本实现显式地区分了「零的位置」和「下一个非零的位置」，逻辑分支更多；标准双指针写法用一个 `write` 指针就同时表达了这两个概念，更简洁。

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 双指针交换（推荐） | O(n) | O(1) | 一趟扫描，代码最短 |
| 覆盖 + 补零 | O(n) | O(1) | 两趟扫描，思路直观 |
| 本仓库实现 | O(n) | O(1) | 显式定位零与非零，分支较多 |

## 代码

```python
class Solution(object):
    def moveZeroes(self, nums):
        """
        :type nums: List[int]
        :rtype: None Do not return anything, modify nums in-place instead.
        """
        first0 = 0
        after0 = 1
        n = len(nums)
        while after0 <= n - 1 or first0 <= n - 1:
            while after0 <= n - 1:
                if nums[after0] != 0 and nums[after0 - 1] == 0:
                    break
                after0 += 1
            while first0 <= n - 1 and nums[first0] != 0:
                first0 += 1
            if after0 > n - 1 or first0 > n - 1:
                break
            if nums[first0] == 0 and nums[after0] != 0:
                t = nums[first0]
                nums[first0] = nums[after0]
                nums[after0] = t
```

## 易错点

- **破坏非零元素的相对顺序**：不能排序，也不能随意交换任意两个元素。必须保证先出现的非零元素先被放置。
- **返回值**：题目要求原地修改、返回 `None`。不要 `return nums`，也不要重新绑定 `nums = ...`（那样调用方看不到修改）。
- **用 `remove` 或 `pop`**：`nums.remove(0)` 是 O(n)，循环删除会退化成 O(n²)，而且会改变数组长度。
- **额外开数组**：`nums[:] = [x for x in nums if x != 0] + ...` 虽然正确，但用了 O(n) 额外空间，不满足原地要求。
- **`write` 指针越界**：`write` 始终不超过 `read`，所以 `nums[write]` 不会越界；但若初始化或更新写错，可能访问非法下标。
- **本实现的边界**：`after0` 从 1 开始，访问 `nums[after0 - 1]` 是安全的；`first0` 在访问前有 `first0 <= n - 1` 的条件。空数组时两个循环都不执行，安全。
- **全零数组**：`after0` 会一直走到 `n`，随后 `break`，数组保持不变，正确。
- **没有零的数组**：`first0` 会走到 `n` 后退出，数组保持不变，正确。
- **单个元素**：`[0]` 和 `[1]` 都不需要移动，本实现能正确退出。
- **`n = 0`**：LeetCode 约束 `1 <= n`，但本实现遇到空数组也不会报错。
