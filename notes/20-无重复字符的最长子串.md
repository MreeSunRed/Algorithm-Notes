# 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

> LeetCode 3 · 难度：中等 · 标签：字符串、哈希表、滑动窗口

## 题目

给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。

```
输入: s = "abcabcbb"
输出: 3
解释: 最长无重复子串是 "abc"，长度为 3。

输入: s = "bbbbb"
输出: 1

输入: s = "pwwkew"
输出: 3
解释: 最长子串是 "wke"；注意 "pwke" 是子序列，不是子串。
```

## 思路

### 为什么用滑动窗口

「子串」要求字符连续。暴力枚举所有子串再判重，至少 O(n²)。

观察一个性质：如果窗口 `[left, right]` 内没有重复字符，那么把 `right` 向右扩一格，只会出现一种冲突 —— 新字符和窗口里某个已有字符重复。此时**不需要从头重来**，只需要把 `left` 跳到冲突字符的下一个位置，窗口就重新合法了。

这就是滑动窗口：`right` 负责扩张，`left` 只在必要时右移，两个指针都只前进不后退，总移动次数 O(n)。

### 本仓库实现：哈希表记录「字符最后一次出现的位置」

```python
d = {}                      # 字符 → 最后一次出现的下标
left = 0
maxlen = 0
for right in range(len(s)):
    if s[right] in d and d[s[right]] >= left:
        left = d[s[right]] + 1
    d[s[right]] = right
    maxlen = max(maxlen, right - left + 1)
```

两个关键点：

1. **为什么要判断 `d[s[right]] >= left`？**
   字典里存的是历史最后位置，它可能已经在窗口左边之外。例如 `"abba"`：处理到最后一个 `a` 时，`a` 的上次位置是 0，而窗口已经收缩到 `left = 2`。此时 `a` 并不在窗口里，`left` **不能**回退到 1 —— 否则窗口会向左扩张，指针不再单调。`>= left` 这个条件保证只有冲突字符确实在窗口内时才移动左边界。

2. **为什么 `left` 可以直接跳到 `d[s[right]] + 1`？**
   只要窗口同时包含「上次出现的该字符」和「当前字符」，就一定重复。左侧所有位置直到上次出现处都不可能构成合法窗口，所以可以一次性跳过，不用逐格收缩。

### 例子走一遍

以 `"abcabcbb"` 为例：

| right | 字符 | 动作 | left | 窗口 | maxlen |
|:-----:|:----:|------|:----:|------|:------:|
| 0 | a | 记录 a=0 | 0 | a | 1 |
| 1 | b | 记录 b=1 | 0 | ab | 2 |
| 2 | c | 记录 c=2 | 0 | abc | 3 |
| 3 | a | a 在窗口内，left=0+1 | 1 | bca | 3 |
| 4 | b | b 在窗口内，left=1+1 | 2 | cab | 3 |
| 5 | c | c 在窗口内，left=2+1 | 3 | abc | 3 |
| 6 | b | b 在窗口内，left=4+1 | 5 | cb | 2 |
| 7 | b | b 在窗口内，left=6+1 | 7 | b | 1 |

答案 3。

### 另一种写法：集合 + while 收缩

用 `set` 维护窗口内的字符，遇到重复就一格一格地移动 `left`：

```python
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        seen = set()
        left = 0
        maxlen = 0
        for right, ch in enumerate(s):
            while ch in seen:
                seen.remove(s[left])
                left += 1
            seen.add(ch)
            maxlen = max(maxlen, right - left + 1)
        return maxlen
```

- 时间仍是 O(n)：每个字符最多被加入、移出各一次
- 逻辑更贴近「窗口模板」，但 `left` 一次只挪一格，常数略大
- 本仓库的字典写法直接跳到冲突位置之后，思路更巧妙

## 复杂度

- **时间 O(n)**：`right` 遍历一次，`left` 单调右移，总移动次数不超过 n
- **空间 O(min(n, σ))**：字典最多存字符集大小 `σ` 个键（本题是小写字母/ASCII，可视为 O(1)）

## 代码

```python
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        """
        :type s: str
        :rtype: int
        """
        d = dict()
        left = 0
        maxlen = 0
        for right in range(0, len(s)):
            if s[right] not in d:
                d[s[right]] = right
            else:
                if d[s[right]] >= left:
                    left = d[s[right]] + 1
                d[s[right]] = right
            maxlen = max(right - left + 1, maxlen)
        return maxlen
```

## 易错点

- **漏掉 `d[s[right]] >= left` 判断**：`"abba"` 是经典反例。处理最后一个 `a` 时上次位置 0 已在窗口外，若无条件 `left = 0 + 1 = 1`，左指针会倒退，窗口错误扩大。必须确认冲突字符仍在窗口内。
- **`left` 更新后忘记同步字典**：无论是否移动 `left`，都要把当前字符的位置更新为 `right`，否则下次冲突时会用过期的位置。
- **用「字符是否出现过」代替「是否在窗口内」**：这两种语义不同。字典记录的是历史出现位置，判断窗口冲突必须结合 `left`。
- **窗口长度算错**：长度是 `right - left + 1`（闭区间），不是 `right - left`。
- **空字符串**：`s = ""` 时循环不执行，返回 0，正确。
- **只有一个字符**：返回 1。
- **子串 vs 子序列**：题目要求连续子串。`"pwwkew"` 的 `"pwke"` 是子序列，答案应为 `"wke"` 的长度 3。
- **返回长度而不是子串**：若要返回具体子串，需要额外记录取得最大长度时的 `left/right`。
- **Unicode / 大小写**：字典按字符本身存储，天然支持任意字符；`"Aa"` 是两个不同字符，不算重复。
