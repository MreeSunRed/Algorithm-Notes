# 打家劫舍 (House Robber)

> LeetCode 198 · 难度：中等 · 标签：数组、动态规划

## 题目

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素是：相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组 `nums`，计算在**不触动警报装置**的情况下，一夜之内能够偷窃到的最高金额。

```
输入: nums = [1,2,3,1]
输出: 4
解释: 偷窃 1 号房屋（金额 1）和 3 号房屋（金额 3），最高金额 = 1 + 3 = 4。

输入: nums = [2,7,9,3,1]
输出: 12
解释: 偷窃 1、3、5 号房屋（金额 2 + 9 + 1 = 12）。
```

## 思路

### 核心约束

不能偷相邻的两间房，但可以隔一间或多间。问题等价于：在数组中选一个**互不相邻**的子集，使元素和最大。

### 标准动态规划

设 `dp[i]` 表示只考虑前 `i + 1` 间房时的最大金额，则：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

- 不偷第 `i` 间：答案等于 `dp[i-1]`
- 偷第 `i` 间：第 `i-1` 间不能偷，答案等于 `dp[i-2] + nums[i]`

时间和空间都是 O(n)，用滚动变量可以把空间降到 O(1)。

### 本仓库实现：原地「必偷当前房」状态

代码直接在 `nums` 上做原地 DP，把 `nums[i]` 改写成「**偷第 i 间房时**能获得的最大金额」：

```
f[i] = nums[i] + max(f[i-2], f[i-3])
```

其中 `f[0] = nums[0]`、`f[1] = nums[1]`、`f[2] = nums[2] + nums[0]`。

**为什么看 `f[i-2]` 和 `f[i-3]`？** 偷第 `i` 间时，第 `i-1` 间不能偷，所以上一次偷窃最多发生在 `i-2`。而 `i-2` 这间也可以选择不偷：如果最优方案截止在 `i-3` 或更早，由于金额非负，把 `i-2` 加进去只会更好，所以最优前缀方案总能调整成「偷了最后两间中的某一间」。因此只需要比较 `f[i-2]` 和 `f[i-3]` 两种「必偷」状态。

**为什么最后返回 `max(nums[-1], nums[-2])`？** 同理，全局最优方案一定偷了最后一间或倒数第二间（否则可以无损地加上后面的非负金额）。所以整个前缀的最优值就是最后两个「必偷」状态的最大值。

以 `[2,7,9,3,1]` 为例：

| 下标 | 原值 | 计算 | 原地结果 |
|:----:|:----:|------|:--------:|
| 0 | 2 | 初始 | 2 |
| 1 | 7 | 初始 | 7 |
| 2 | 9 | `9 + nums[0] = 11` | 11 |
| 3 | 3 | `3 + max(nums[1], nums[0]) = 10` | 10 |
| 4 | 1 | `1 + max(nums[2], nums[1]) = 12` | 12 |

最终 `max(12, 10) = 12`，与标准 DP 一致。

**长度特判**：

- 长度 1：直接返回 `nums[0]`
- 长度 2：返回 `max(nums[0], nums[1])`
- 长度 3 起才进入递推，避免访问 `nums[i-3]` 越界

### 推荐的滚动变量写法

原地 DP 虽然省空间，但会修改输入，而且递推式不如标准式直观。工程上更推荐：

```python
prev2, prev1 = 0, 0          # dp[i-2], dp[i-1]
for x in nums:
    prev2, prev1 = prev1, max(prev1, prev2 + x)
return prev1
```

- 不修改输入，空间 O(1)
- 递推关系与数学定义一一对应，边界自然（空数组返回 0）

## 复杂度

- **时间 O(n)**：一次遍历
- **空间 O(1)**：原地 DP 只用了常数个临时变量（但会修改输入数组）

## 代码

```python
class Solution(object):
    def rob(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums) - 1
        if n == 0:
            return nums[0]
        if n == 1:
            return max(nums[0], nums[1])
        nums[2] = nums[2] + nums[0]
        for i in range(3, len(nums)):
            nums[i] = nums[i] + max(nums[i - 2], nums[i - 3])
        return max(nums[-1], nums[-2])
```

## 易错点

- **返回 `nums[-1]` 而不是最后两个的最大值**：最优方案可能不偷最后一间。例如 `[1,2,3,1]` 原地计算后最后两个值是 `4` 和 `3`，最大值为 `4`，只取 `nums[-1]` 会得到错误的 `3`。
- **长度 1 / 2 没有特判**：直接访问 `nums[2]` 会越界；长度 2 时也不存在 `i-2` 的合法递推。
- **原地修改输入**：`nums` 被改写成 DP 数组，调用方若还要用原数据会拿到错误结果。需要保留原数组时先 `copy()`，或改用滚动变量写法。
- **把「不能相邻」理解成「必须隔一间」**：可以连续跳过任意多间，只要不选相邻元素即可。
- **只考虑 `dp[i-1]`**：漏掉「偷当前 + 隔一间」的分支。
- **金额为负时套用本实现**：题目保证金额非负，「最优方案可调整到偷最后两间之一」的论证依赖非负性；若允许负数，应使用标准 `max(dp[i-1], dp[i-2] + nums[i])`。
- **空数组**：LeetCode 保证 `1 <= nums.length`；本实现遇到空数组会在 `nums[2]` 处越界，属于约束外输入。
- **`n` 的含义**：代码里 `n` 是「长度减一」，即最后一个下标，不是长度；比较 `n == 0` / `n == 1` 时不要混淆。
- **大数溢出**：Python 无溢出；其他语言在 100 间房、每间 400 的约束下总和最多 20000，32 位足够。

|------|------|------|
| `[5]` | `5` | 单间房 |

| `[7,2]` | `7` | 两间房顺序无关 |
