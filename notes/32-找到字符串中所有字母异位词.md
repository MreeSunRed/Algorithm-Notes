# 找到字符串中所有字母异位词 (Find All Anagrams in a String)

> LeetCode 438 · 难度：中等 · 标签：字符串、哈希表、滑动窗口

## 题目

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**异位词**（字母异位词）的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**异位词**指由相同字母重排列形成的字符串（包括相同的字符串）。

```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引 0 的子串是 "cba"，它是 "abc" 的异位词。
起始索引 6 的子串是 "bac"，它是 "abc" 的异位词。

输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引 0 的子串是 "ab"，是 "ab" 的异位词。
起始索引 1 的子串是 "ba"，是 "ab" 的异位词。
起始索引 2 的子串是 "ab"，是 "ab" 的异位词。
```

## 思路

### 固定长度的滑动窗口

异位词的长度一定和 `p` 相同（都等于 `len(p)`）。所以问题变成：

> 在 `s` 中枚举所有长度为 `len(p)` 的子串，判断它和 `p` 的**字符计数**是否完全相同。

窗口长度固定，滑动时每次只需要：

1. 把移出窗口的字符计数减 1
2. 把新进入窗口的字符计数加 1
3. 比较当前窗口的计数与 `p` 的计数

不需要每次都重新统计整个窗口，因此从 O(n · m) 降到 O(n + m)。

### 本仓库实现：Counter 比较

```python
check = Counter(p)
window = Counter(s[:step])      # 第一个窗口
if check == window:
    res.append(0)

for i in range(0, n - step):
    window[s[i]] -= 1           # 左边移出
    window[s[i + step]] += 1    # 右边移入
    if window[s[i]] == 0:
        del window[s[i]]        # 清理计数为 0 的键
    if check == window:
        res.append(i + 1)       # 新窗口的起始下标
```

**下标含义**：循环变量 `i` 是「即将移出的字符」的下标，滑动后新窗口从 `i + 1` 开始，所以命中时记录 `i + 1`。

**为什么要删除计数为 0 的键？**

`Counter` 的相等比较在不同 Python 版本中对待「计数为 0 的键」的行为不完全一致。把 0 计数的键删掉，可以保证 `window` 和 `check` 的结构干净，比较结果稳定，也避免字典无限增长（虽然本题字符集固定，影响不大）。

**为什么比较 `Counter` 是 O(1) 的？** 本题限定小写英文字母，字符集大小固定为 26，比较两个字典的固定规模是常数时间。

### 另一种写法：长度 26 的计数数组

```python
class Solution(object):
    def findAnagrams(self, s, p):
        n, m = len(s), len(p)
        if m > n:
            return []
        target = [0] * 26
        window = [0] * 26
        for ch in p:
            target[ord(ch) - ord('a')] += 1
        for ch in s[:m]:
            window[ord(ch) - ord('a')] += 1
        res = []
        if window == target:
            res.append(0)
        for i in range(n - m):
            window[ord(s[i]) - ord('a')] -= 1
            window[ord(s[i + m]) - ord('a')] += 1
            if window == target:
                res.append(i + 1)
        return res
```

- 数组比较固定 26 次，整体 O(26n)，可视为 O(n)
- 不需要处理「计数为 0 的键」，逻辑更直白
- 如果字符集更大（Unicode），用 `Counter` 更通用

## 复杂度

- **时间 O(n + m)**：初始化计数 O(m)，滑动窗口每步 O(1)（字符集固定）
- **空间 O(1)**：`Counter` / 计数数组的大小取决于字符集，最多 26（小写字母）

## 代码

```python
import collections


class Solution(object):
    def findAnagrams(self, s, p):
        """
        :type s: str
        :type p: str
        :rtype: List[int]
        """
        res = []
        n = len(s)
        step = len(p)
        check = collections.Counter(p)
        window = collections.Counter(s[:step])
        if check == window:
            res.append(0)
        for i in range(0, n - step):
            window[s[i]] -= 1
            window[s[i + step]] += 1
            if window[s[i]] == 0:
                del window[s[i]]
            if check == window:
                res.append(i + 1)
        return res
```

## 易错点

- **窗口长度不是 `len(p)`**：异位词必须等长，窗口大小一定要固定为 `m = len(p)`。
- **下标差一**：循环里 `i` 是移出的位置，滑动后的新窗口起点是 `i + 1`。记录 `i` 会整体错位。
- **移入/移出的顺序**：先减左边、再加右边，或者反过来，计数结果一样，但新窗口的索引必须对应正确；推荐「先移出 `i`，再移入 `i + m`」。
- **`p` 比 `s` 长**：此时不存在合法窗口。本实现中 `window = Counter(s[:step])` 长度不足，`check != window`，且 `range(0, n - step)` 为空，返回 `[]`，正确。
- **空字符串**：`s = ""` 时返回 `[]`；`p` 为空不符合题目约束（`1 <= len(p)`），若允许空串，逻辑需要单独定义。
- **只比较字符集合而不是计数**：`"aab"` 和 `"abb"` 的字符集合相同，但计数不同，不是异位词。必须比较计数。
- **不删除 0 计数的键**：在部分 Python 版本中会让 `Counter` 比较出现意外结果，建议删除或使用数组。
- **重复字符**：`"abab"` 中 `"ab"`、`"ba"` 都算，每个起始位置都要检查，不能去重。
- **返回的是起始索引**：不是子串本身，也不是结束索引。
- **大小写与字符集**：题目限定小写英文字母；若扩展到 Unicode，`ord(ch) - ord('a')` 的下标法会失效，改用 `Counter`。

## 边界测试

| 输入 | 输出 | 说明 |
|------|------|------|
| `"cbaebabacd", "abc"` | `[0,6]` | 经典用例 |
