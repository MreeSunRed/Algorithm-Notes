# 杨辉三角 (Pascal's Triangle)

> LeetCode 118 · 难度：简单 · 标签：数组、动态规划

## 题目

给定一个非负整数 `numRows`，生成杨辉三角的前 `numRows` 行。

在杨辉三角中，每个数是它左上方和右上方的数之和，每行首尾都是 `1`。

```
输入: numRows = 5
输出: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

输入: numRows = 1
输出: [[1]]
```

## 思路

### 递推关系

设第 `i` 行（从 0 开始计）第 `j` 个数为 `s[i][j]`，则：

```
s[i][j] = s[i-1][j-1] + s[i-1][j]
```

首尾两列满足 `s[i][0] = s[i][i] = 1`。

直接按这个式子写，需要单独处理 `j = 0` 和 `j = i` 的边界。

### 本仓库实现：上一行两侧补 0

把上一行左右各补一个 `0`，边界就自然消失了：

```python
pre = [0] + res[i - 2] + [0]
cur = [pre[j] + pre[j + 1] for j in range(i)]
```

以第 3 行（长度 3）为例，上一行是 `[1, 1]`：

```
pre = [0, 1, 1, 0]
cur[0] = pre[0] + pre[1] = 0 + 1 = 1
cur[1] = pre[1] + pre[2] = 1 + 1 = 2
cur[2] = pre[2] + pre[3] = 1 + 0 = 1
```

得到 `[1, 2, 1]`，首尾的 `0` 正好让边界值落在 `1` 上，不需要任何 `if` 判断。

**为什么 `range(i)`？** 第 `i` 行（代码里的 `i` 从 2 开始，表示第 3 行）有 `i` 个数，补零后的 `pre` 长度为 `i + 1`，所以 `pre[j] + pre[j + 1]` 对 `j = 0..i-1` 都合法。

**`res[i - 2]` 是哪一行？** `res` 里已有 `i - 1` 行（下标 `0..i-2`），最后一行就是上一行。`i` 从 2 开始，所以第一轮取的是 `res[0] = [1]`。

### 其他写法

- **逐行构造 + 中间项求和**：每行先放 `1`，中间项由上一行相邻元素相加，末尾再补 `1`。逻辑直白，但要处理长度变化。
- **原地倒序更新**：只维护一行，从右往左更新 `row[j] += row[j-1]`，可以省掉所有历史行；但本题要求返回整个三角形，历史行必须保留。
- **组合数公式**：第 `i` 行第 `j` 个数是 `C(i, j)`，可以按 `C(i,j) = C(i,j-1) * (i-j+1) / j` 递推。适合只求某一行（见 119 题）。

## 复杂度

- **时间 O(numRows²)**：第 `i` 行要计算 `i` 个数，总元素数为 `1 + 2 + ... + numRows = numRows(numRows+1)/2`
- **空间 O(numRows²)**：返回值本身要存下整个三角形；除返回值外只用了常数级临时变量

## 代码

```python
class Solution(object):
    def generate(self, numRows):
        """
        :type numRows: int
        :rtype: List[List[int]]
        """
        # s[i][j]=s[i-1][j-1]+s[i-1][j]
        if numRows == 1:
            return [[1]]
        res = [[1]]
        for i in range(2, numRows + 1):
            pre = [0] + res[i - 2] + [0]
            cur = [pre[j] + pre[j + 1] for j in range(i)]
            res.append(cur)

        return res
```

## 易错点

- **忘记提前返回 `numRows == 1`**：`res` 初始化为 `[[1]]` 后，循环从 2 开始；如果不特判，`numRows = 1` 其实也能返回 `[[1]]`，特判只是让意图更明确。真正需要小心的是 `numRows = 0`。
- **`numRows = 0` 的语义**：LeetCode 约束 `1 <= numRows <= 30`；本实现遇到 0 会返回 `[[1]]`，不符合「前 0 行」的直觉。若题目允许 0，应在开头返回 `[]`。
- **行号与长度混淆**：第 `i` 行有 `i` 个元素，不是 `i + 1` 个（这里 `i` 从 1 开始计）。补零后 `pre` 的长度是 `i + 1`，列表推导的上界是 `i`。
- **索引写成 `res[i - 1]`**：`res` 下标从 0 开始，第 `i` 行的上一行是 `res[i - 2]`。
- **补零方向**：必须左右各补一个 `0`，只补一边会让首尾计算出错。
- **直接修改上一行**：`row = res[-1]` 后原地 `append` 会污染已保存的结果；需要新列表。
- **返回值类型**：返回 `List[List[int]]`，不要摊平成一维数组。
- **大数问题**：Python 整数无溢出；其他语言在 `numRows = 30` 时中间值约为 `C(29,14) ≈ 7.7e7`，仍在 32 位范围内，但更大行数需用 64 位。
