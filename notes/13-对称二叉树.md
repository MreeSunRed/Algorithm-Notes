# 对称二叉树 (Symmetric Tree)

> LeetCode 101 · 难度：简单 · 标签：树、深度优先搜索、广度优先搜索、二叉树

## 题目

给你一个二叉树的根节点 `root`，检查它是否轴对称。

```
输入: root = [1,2,2,3,4,4,3]
输出: true

      1
    /   \
   2     2
  / \   / \
 3   4 4   3

输入: root = [1,2,2,null,3,null,3]
输出: false
```

## 思路

### 对称的本质：两棵树互为镜像

轴对称不是「左子树等于右子树」，而是「左子树和右子树**互为镜像**」。

镜像的定义可以递归地写出来。两棵树 `a`、`b` 互为镜像，当且仅当：

1. `a` 和 `b` 的值相等
2. `a` 的左子树与 `b` 的**右**子树互为镜像
3. `a` 的右子树与 `b` 的**左**子树互为镜像

注意第 2、3 条是**交叉**的：左边对右边，右边对左边。这是整道题最核心的一句，也是和「判断两棵树相同」最大的区别。

### 递归：check(a, b)

把上面的定义直接翻译成代码：

```python
def check(a, b):
    if a is None and b is None:
        return True          # 两边都空，镜像成立
    if a is None or b is None:
        return False         # 只有一边空，结构不对称
    return (a.val == b.val
            and check(a.left, b.right)
            and check(a.right, b.left))
```

然后在主函数里调用 `check(root, root)`。

**为什么传两次 `root` 也能对？** 第一次比较是 `root` 与 `root` 自己，值必然相等，相当于跳过了「根节点和谁对称」这一步；真正起作用的是随后展开的 `check(root.left, root.right)`。这样写省去了对根节点为空的特判，代码最短。

也可以更直白地写 `return check(root.left, root.right)`（根为空时先特判），少一次无意义的调用。

### 迭代：队列里存「待比较的节点对」

递归改成显式队列，思路完全一致：

```python
from collections import deque

class Solution(object):
    def isSymmetric(self, root):
        if not root:
            return True
        queue = deque([(root.left, root.right)])
        while queue:
            a, b = queue.popleft()
            if a is None and b is None:
                continue
            if a is None or b is None or a.val != b.val:
                return False
            queue.append((a.left, b.right))   # 交叉入队
            queue.append((a.right, b.left))
        return True
```

- 时间 O(n)，空间 O(w)（`w` 为树宽，最坏 O(n)）
- 把队列换成栈就是 DFS 版本，判断逻辑不变

### 一个看似可行、实际错误的思路

「中序遍历结果是不是回文」—— 这是**必要但不充分**的条件。

反例：`[1,2,2,2,null,2]`

```
      1
    /   \
   2     2
  /     /
 2     2
```

中序遍历是 `[2,2,1,2,2]`，确实是回文，但这棵树并不对称（左孩子的左孩子是 2，右孩子的左孩子也是 2，镜像位置应该对应右孩子的右孩子，而那里是空）。所以必须做**结构上的镜像比较**，不能只看遍历序列。

## 复杂度

- **时间 O(n)**：每个节点最多被比较一次
- **空间 O(h)**：递归栈深度等于树高；平衡树 O(log n)，退化链表 O(n)
- 迭代 BFS 的空间是 O(w)，最坏 O(n)

## 代码

```python
class Solution:
    def isSymmetric(self, root):
        def check(a, b):
            if a is None and b is None:
                return True
            if a is None or b is None:
                return False
            return a.val == b.val and check(a.left, b.right) and check(a.right, b.left)
        return check(root, root)
```

## 易错点

- **写成「左对左、右对右」**：那是判断两棵树是否**相同**（[100. 相同的树](https://leetcode.cn/problems/same-tree/)），不是镜像。对称必须交叉比较：`a.left` 对 `b.right`，`a.right` 对 `b.left`。
- **空节点判断顺序**：必须先处理「都为空 → True」和「只有一个为空 → False」，再访问 `a.val`。顺序反了会对 `None` 取属性，直接报错。
- **只比较值不比较结构**：值相等不代表结构对称，必须同时递归比较孩子。
- **空树**：`root = null` 时是对称的，返回 `True`。`check(None, None)` 正好返回 `True`。
- **单节点**：必然对称，返回 `True`。
- **`check(root, root)` 的语义**：它成立的前提是 `check` 实现的是「镜像」而不是「相同」。如果错写成相同树的比较，传两次 `root` 会永远返回 `True`，把错误藏起来。
- **中序遍历回文不等于对称**：见上面的反例，只能作为必要条件的快速筛选，不能作为充要判断。
- **递归深度**：退化成链时递归 O(n) 层，节点数很大时可能栈溢出，可改迭代。
- **只比较值，不比较节点身份**：对称看的是结构与值，不是同一个对象。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[1,2,2,3,4,4,3]` | `true` | 经典对称树 |
| `[1,2,2,null,3,null,3]` | `false` | 值相同但结构不对称 |
| `[1,2,2]` | `true` | 只有一层孩子 |
| `[1,2,3]` | `false` | 根的两个孩子值不同 |
| `[1]` | `true` | 单节点 |
| `[]` | `true` | 空树视为对称 |
| `[1,2,2,2,null,2]` | `false` | 中序回文但结构不对称的反例 |
