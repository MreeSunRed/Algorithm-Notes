# 反转二叉树 (Invert Binary Tree)

> LeetCode 226 · 难度：简单 · 标签：树、深度优先搜索、广度优先搜索、二叉树

## 题目

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

「翻转」指把每个节点的左右子树交换：

```
输入:          输出:
      4             4
    /   \         /   \
   2     7  →    7     2
  / \   / \     / \   / \
 1   3 6   9   9   6 3   1
```

## 思路

### 递归：翻转 = 交换左右孩子 + 递归翻转两棵子树

翻转整棵树，可以拆成三件独立的事：

1. 交换根节点的左右孩子
2. 翻转（新的）左子树
3. 翻转（新的）右子树

第 2、3 步和原问题是**同一个问题**，只是规模更小 —— 这就是递归的结构。空节点没有孩子可交换，直接返回，作为递归的终止条件。

**关键不变量**：递归函数 `invertTree(node)` 返回时，以 `node` 为根的整棵子树已经完成翻转。归纳地看：

- 空树：翻转后仍是空树，成立
- 非空：交换左右孩子后，对两棵子树分别递归；由归纳假设它们各自已翻转，于是整棵树翻转完成

### 交换和递归的先后顺序

先交换再递归，或先递归再交换，**都可以**：

- 先交换：递归的是交换后的 `left`、`right`，但两者都是原来的孩子，只是顺序对调，最终两棵子树都会被处理
- 先递归：处理的还是原来的两个孩子，处理完再交换，结果一样

真正不能省的是「两个子树都要递归」——只递归一边会留下未翻转的子树。

### 迭代写法：队列 / 栈

递归的隐式栈可以换成显式容器。用队列做层序遍历，每弹出一个节点就交换它的左右孩子，再把两个孩子入队：

```python
from collections import deque

class Solution(object):
    def invertTree(self, root):
        if not root:
            return None
        queue = deque([root])
        while queue:
            node = queue.popleft()
            node.left, node.right = node.right, node.left
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        return root
```

把 `deque` 换成 `list` 并用 `pop()`，就是 DFS 版本。两者都是 O(n) 时间，区别只在访问顺序。

## 复杂度

- **时间 O(n)**：每个节点恰好被访问一次（交换 + 递归）
- **空间 O(h)**：递归栈深度等于树高；平衡树 O(log n)，退化成链表时 O(n)
- 迭代 BFS 的空间是 O(w)，`w` 为树的最大宽度，最坏 O(n)

## 代码

```python
class Solution(object):
    def invertTree(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: Optional[TreeNode]
        """
        if root == None:
            return
        temp = root.left
        root.left = root.right
        root.right = temp
        self.invertTree(root.left)
        self.invertTree(root.right)
        return root
```

## 易错点

- **忘记返回 `root`**：题目要求返回翻转后的根节点。递归调用内部的返回值可以忽略，但最外层必须返回 `root`；漏掉会返回 `None`。
- **空节点直接 `return`**：返回 `None` 是正确的（空树翻转后还是空树），不需要额外构造节点。
- **只交换不递归**：只处理根节点，子树没有翻转，整棵树仍是「半翻转」状态。
- **只递归一个孩子**：另一个子树会保持原样，结果错误。
- **交换用临时变量或元组解包**：`temp` 写法正确；Python 也可以直接 `root.left, root.right = root.right, root.left`，更简洁。
- **误以为要按值重排**：翻转是**结构**操作，交换的是指针，不是节点里的 `val`，也不涉及排序。
- **递归深度**：退化成链的树有 O(n) 层递归，节点数很大时可能触发 Python 递归上限，可改用迭代。
- **不要和「对称」混淆**：本题是无条件交换左右子树；[101. 对称二叉树](13-对称二叉树.md) 是判断左右是否互为镜像，不修改树。

## 边界测试

| 输入 | 输出 | 说明 |
|------|------|------|
| `[4,2,7,1,3,6,9]` | `[4,7,2,9,6,3,1]` | 经典完全二叉树 |
| `[]` | `[]` | 空树 |
| `[1]` | `[1]` | 单节点，交换无变化 |
| `[1,2]` | `[1,null,2]` | 只有左孩子，翻转后变成只有右孩子 |
| `[1,null,2]` | `[1,2]` | 只有右孩子，翻转后变成只有左孩子 |
