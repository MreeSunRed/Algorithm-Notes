# 环形链表 (Linked List Cycle)

> LeetCode 141 · 难度：简单 · 标签：链表、哈希表、双指针

## 题目

给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

- 如果链表中存在环，则返回 `true`
- 否则，返回 `false`

```
输入: head = [3,2,0,-4], pos = 1
输出: true
解释: 链表中有一个环，其尾部连接到第二个节点。
```

## 思路

### 思路一：哈希表记录访问过的节点（本仓库实现）

从 `head` 出发逐个遍历节点：

- 如果当前节点**之前访问过**，说明绕回了老路 → 有环
- 否则把当前节点记入集合，继续前进
- 走到 `None` 还没重复 → 无环

本仓库用 `dict` 存节点，`s[l] = True`；用 `set` 更直接：`s.add(l)`。两者查找都是 O(1)。

**必须存节点对象，不能存 `val`。** 链表里完全可能有两个值相同但互相独立的节点；按值判重会把「值重复」误判成「有环」。`ListNode` 没有重写 `__eq__` / `__hash__`，默认按对象身份比较，正好符合需求。

### 思路二：快慢指针（Floyd 判圈，O(1) 空间）

哈希表需要 O(n) 空间。更优的解法只用两个指针：

```python
class Solution(object):
    def hasCycle(self, head):
        slow = fast = head
        while fast and fast.next:
            slow = slow.next          # 每步走 1
            fast = fast.next.next     # 每步走 2
            if slow is fast:
                return True
        return False
```

**为什么有环一定会相遇？**

- 无环：`fast` 会先走到 `None`，循环自然结束，返回 `False`
- 有环：两个指针都会进入环。`fast` 每轮比 `slow` 多走 1 步，相当于在环内以**相对速度 1** 追赶 `slow`。只要环存在，两者距离会每轮缩短 1，最终必然重合（不会跳过）

**为什么用 `is` 而不是 `==`？** 这里是判断「是不是同一个节点」，对象身份比较语义更明确；默认的 `==` 对 `ListNode` 也是身份比较，但显式写 `is` 更不容易误解。

## 复杂度

| 解法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 哈希表（本仓库） | O(n) | O(n) | 直观，能顺手记录访问路径 |
| 快慢指针 | O(n) | **O(1)** | 最优，面试首选 |

- 快慢指针在无环时最多走约 n/2 轮；有环时，`slow` 进入环后最多再走一圈就会相遇，仍是 O(n)

## 代码

```python
class Solution(object):
    def hasCycle(self, head):
        """
        :type head: ListNode
        :rtype: bool
        """
        s = dict()
        l = head
        while l != None:
            if l in s:
                return True
            s[l] = True
            l = l.next
        return False
```

## 易错点

- **按 `val` 判重**：`[1,1]` 这种值重复但无环的链表会被误判为有环。必须比较节点对象本身。
- **用 `list` 存节点再 `in` 查找**：`in` 对列表是 O(n)，整体退化成 O(n²)。用 `set` / `dict` 才能 O(1) 查找。
- **快指针的越界判断**：`while fast and fast.next` 两个条件都要有。漏掉 `fast.next`，`fast.next.next` 会对 `None` 取属性；漏掉 `fast`，空链表直接崩溃。
- **相遇判断的位置**：可以先移动再比较，也可以先比较再移动，但要保证两个指针同步推进；只移动一个就判断会误报。
- **空链表与单节点**：`head = None` 返回 `False`；单节点且 `next = None` 也返回 `False`；单节点自环（`next` 指向自己）返回 `True`。
- **题目只要求判断有没有环**：不要顺手返回环的入口，那是 [142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/) 的要求，需要额外的数学推导。
- **不要修改链表**：判环不应改变 `next` 指针，否则可能破坏评测系统构造的环。
- **`pos` 不是参数**：不要试图读取 `pos`，函数签名里只有 `head`。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[]` | `false` | 空链表 |
| `[1]`，无环 | `false` | 单节点 |
| `[1]`，`next` 指向自己 | `true` | 单节点自环 |
| `[1,2,3,4]`，尾部连到下标 1 | `true` | 经典有环 |
| `[1,2,3]`，无环 | `false` | 普通链表 |
| `[1,1]`，无环 | `false` | 值重复但无环，不能按值判重 |
