# 二叉树的最大深度 (Maximum Depth of Binary Tree)

> LeetCode 104 · 难度：简单 · 标签：树、深度优先搜索、广度优先搜索、二叉树

## 题目

给定一个二叉树 `root`，返回其**最大深度**。

二叉树的最大深度是指从根节点到最远叶子节点的**最长路径上的节点数**。

```
输入: root = [3,9,20,null,null,15,7]
输出: 3

      3
     / \
    9  20
      /  \
     15   7
```

最长的路径是 `3 → 20 → 15`（或 `3 → 20 → 7`），共 3 个节点。

## 思路

### 递归：最大深度由子树决定

一个树的最大深度，只可能来自左右两棵子树中更深的那一棵：

```
depth(root) = 0                        如果 root 为空
depth(root) = 1 + max(depth(left), depth(right))   否则
```

这是**自底向上**的视角：先分别求出左右子树的深度，取较大者，再加上根节点自己这一层。

### 本仓库的实现：自顶向下传高度

代码换了一个方向 —— 带着「当前高度」往下走，走到空节点时返回这个高度，再在每层取左右较大值：

```python
def inorder(root, height):
    if root == None:return height
    left = inorder(root.left, height + 1)
    right = inorder(root.right, height + 1)
    return max(left, right)
return inorder(root, 0)
```

两种视角是等价的：

| 视角 | 传递方向 | 空节点返回 | 合并方式 |
|------|----------|------------|----------|
| 自底向上 | 深度从子树往上汇总 | 0 | `1 + max(左, 右)` |
| 自顶向下（本实现） | 高度从根往下传 | 当前 `height` | `max(左, 右)` |

**为什么自顶向下也正确？** 每个节点都会把自己的层数 `height + 1` 传给两个孩子；空节点没有孩子，它返回的 `height` 就是「走到这里为止经过的节点数」。所有叶子路径中最大的那个值，自然就是最大深度。

### 另一种写法：BFS 数层数

层序遍历（队列）每处理完一层，深度加一，最后得到的层数就是最大深度。时间 O(n)，空间 O(w)（`w` 为树的最大宽度）。适合「不想递归」或想顺便练 BFS 的场景。

## 复杂度

- **时间 O(n)**：每个节点访问一次
- **空间 O(h)**：递归栈深度等于树高。平衡树 O(log n)，退化成链表时 O(n)

BFS 写法的空间是 O(w)，最坏（完全二叉树最后一层）也是 O(n)。

## 代码

```python
class Solution(object):
    def maxDepth(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: int
        """
        def inorder(root, height):
            if root == None:return height
            left = inorder(root.left, height + 1)
            right = inorder(root.right, height + 1)
            return max(left, right)
        return inorder(root, 0)
```

等价的、更短的递归写法：

```python
class Solution(object):
    def maxDepth(self, root):
        if not root:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

## 易错点

- **深度按「节点数」算，不是「边数」**：单节点树的深度是 1，不是 0。LeetCode 的定义是根到最远叶子的节点数；部分教材里的「高度」按边数算，会差 1，别混用。
- **空树返回 0**：`root = null` 时最大深度为 0，本实现 `inorder(None, 0)` 正好返回 0。
- **内层函数叫 `inorder` 是误导**：它既不是中序，也不是任何一种「输出序列」的遍历 —— 先递归左、再递归右、最后合并，属于**后序**（DFS）。`dfs` / `depth` 之类的名字更准确。逻辑本身没有问题。
- **`height + 1` 要同时传给两个孩子**：漏传或只给一边加一，会让深度算少。
- **空节点返回的是 `height` 而不是 0**：自顶向下写法里，`height` 是由上层累计下来的；若在空节点处返回 0，等于把之前的层数全丢掉。
- **不要和「最小深度」混淆**：LeetCode 111 中，若一个节点只有一侧孩子，另一侧的空子树**不能**算作叶子，需要额外判断。最大深度没有这个问题，因为空子树永远不可能是「更深」的那一侧。
- **递归深度**：退化链表上有 O(n) 层递归，n 很大时可能触发 Python 递归上限，需改迭代 / BFS。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[3,9,20,null,null,15,7]` | `3` | 经典完全二叉树 |
| `[]` | `0` | 空树 |
| `[1]` | `1` | 单节点 —— 深度按节点数算 |
| `[1,2]` | `2` | 只有左孩子 |
| `[1,null,2,null,3]` | `3` | 只有右孩子的链，考验递归到底 |
| `[1,2,3,4,null,null,null,5]` | `4` | 左右不平衡，最长路径在左侧 |
