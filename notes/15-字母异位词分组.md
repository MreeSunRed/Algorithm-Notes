# 字母异位词分组 (Group Anagrams)

> LeetCode 49 · 难度：中等 · 标签：数组、哈希表、字符串、排序

## 题目

给你一个字符串数组，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。

**字母异位词**是由重新排列源单词的所有字母得到的一个新单词。

```
输入: strs = ["eat","tea","tan","ate","nat","bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

输出中每组的顺序、组与组之间的顺序都不重要，只要同一组内的单词互为异位词即可。

## 思路

### 关键：为每个单词找一个「标准形」

判断两个单词是否互为异位词，最直接的办法是排序后比较：

```
eat → aet
tea → aet     相等 → 同一组
tan → ant
nat → ant     相等 → 同一组
```

排序后的字符串是一个**规范化的键**：互为异位词的单词，键一定相同；不是异位词的单词，键一定不同。

于是问题变成一道普通的「按 key 分组」题：

1. 遍历每个单词，计算它的键 `"".join(sorted(word))`
2. 哈希表 `key → [该组的单词]`
3. 最后把所有值收集起来返回

本仓库的实现正是这个思路：字典里没有该键就新建列表，有就追加。

### 为什么排序能作为键

异位词的定义是「字母相同、只是顺序不同」。排序消除了顺序信息，只保留「有哪些字母、各多少个」。这正好是异位词的等价类特征。

反过来也成立：排序结果相同 ⇒ 两个单词的字母多重集相同 ⇒ 互为异位词。

### 另一种键：26 个字母的计数

如果不想对每个单词排序，可以统计 26 个字母的出现次数，把计数元组作为键：

```python
from collections import defaultdict

class Solution(object):
    def groupAnagrams(self, strs):
        groups = defaultdict(list)
        for word in strs:
            counts = [0] * 26
            for ch in word:
                counts[ord(ch) - ord('a')] += 1
            groups[tuple(counts)].append(word)
        return list(groups.values())
```

- 时间从 O(m log m) 降到 O(m)（`m` 为单词长度），总体 O(n·m)
- 空间仍是 O(n·m)
- 计数数组必须转成 `tuple` 才能作为字典键，`list` 是不可哈希的

### 代码简化：defaultdict

本仓库用 `if t in s` 手动判断键是否存在。用 `defaultdict(list)` 可以省掉分支：

```python
from collections import defaultdict

groups = defaultdict(list)
for word in strs:
    groups["".join(sorted(word))].append(word)
return list(groups.values())
```

## 复杂度

设 `n` 为单词数量，`m` 为单词的最大长度。

| 键的构造方式 | 时间 | 空间 |
|--------------|:----:|:----:|
| 排序（本仓库） | O(n · m log m) | O(n · m) |
| 26 字母计数 | **O(n · m)** | O(n · m) |

- 空间里 O(n·m) 主要是存放所有单词及分组结果；哈希表本身的键值对是 O(n)
- 排序键在 `m` 较小（英文单词通常很短）时完全够用，代码也最短

## 代码

```python
class Solution(object):
    def groupAnagrams(self, strs):
        """
        :type strs: List[str]
        :rtype: List[List[str]]
        """
        s = dict()
        for i in strs:
            t = "".join(sorted(i))
            if t in s:
                s[t].append(i)
            else:
                s[t] = [i]
        res = []
        for i in s.values():
            res.append(i)
        return res
```

## 易错点

- **键必须是可哈希的**：`sorted(word)` 返回的是 `list`，不能直接当字典键。必须 `"".join(...)` 成字符串，或 `tuple(...)` 成元组。
- **不要修改原单词**：`sorted()` 返回新列表，原字符串不变；如果直接 `word.sort()` 会报错（字符串不可变），对列表也会破坏输入。
- **输出顺序不重要**：LeetCode 接受任意组顺序和组内顺序。不要为了让结果「看起来整齐」而额外排序，除非题目要求。
- **空字符串**：`strs` 中可以有 `""`，排序后键仍是 `""`，所有空串会归到同一组，本实现天然支持。
- **空输入**：`strs = []` 时字典为空，返回 `[]`，正确。
- **重复单词**：同一个单词出现多次时，会全部追加进同一组（列表允许重复），这正是题目要求。
- **大小写与字符集**：题目限定小写英文字母。若扩展到 Unicode，排序键仍然成立；26 计数法则需要换更大的字符集。
- **用值做键的误区**：不能只按首字母或长度分组，`"ab"` 和 `"ba"` 首字母不同但互为异位词。
- **`dict` 的迭代顺序**：Python 3.7+ 保持插入顺序，所以结果稳定；但即使不保持，题目也不要求顺序。

## 边界测试

| 输入 | 输出（任意顺序） | 说明 |
|------|------------------|------|
| `["eat","tea","tan","ate","nat","bat"]` | `[["bat"],["nat","tan"],["ate","eat","tea"]]` | 经典用例 |
| `[""]` | `[[""]]` | 空字符串单独一组 |
| `["a"]` | `[["a"]]` | 单元素 |
| `[]` | `[]` | 空输入 |
| `["abc","bca","cab","xyz"]` | `[["abc","bca","cab"],["xyz"]]` | 三词同组 + 独立词 |
| `["ddddddddddg","dgggggggggg"]` | `[["ddddddddddg"],["dgggggggggg"]]` | 字母计数相同但种类不同，不能误并 |
