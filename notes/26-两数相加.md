# 两数相加 (Add Two Numbers)

> LeetCode 2 · 难度：中等 · 标签：链表、数学、递归

## 题目

给你两个**非空**的链表，表示两个非负的整数。它们每位数字都是按照**逆序**的方式存储的，并且每个节点只能存储**一位**数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

```
输入: l1 = [2,4,3], l2 = [5,6,4]
输出: [7,0,8]
解释: 342 + 465 = 807

输入: l1 = [9,9,9,9], l2 = [9,9,9]
输出: [8,9,9,0,1]
解释: 9999 + 999 = 10998
```

## 思路

### 逆序存储是一个便利

数字按**逆序**存放：链表头是**个位**，往后依次是十位、百位……

这正好符合竖式加法的计算方向 —— 从最低位开始，逐位相加并向后进位。两个链表从头部同步向后遍历，就是天然的「从右往左算」。

如果题目改成顺序存储（LeetCode 445），就要先反转链表或用栈；本题不需要。

### 本仓库实现：递归逐位相加

递归函数 `plusList(l1, l2, add)` 负责计算「当前这一位」：

1. **终止条件**：两个链表都走完
   - 没有进位 → 返回 `None`
   - 还有进位 → 返回一个值为 `1` 的节点（最高位进位）
2. **取出当前位**：如果某个链表先走完，就把它那一位当作 0（只取另一个链表的值）
3. **相加**：`l1.val + l2.val + add`
4. **处理进位**：和 ≥ 10 时，本位减 10，进位记为 1
5. **建节点并递归**：当前节点是 `plusNum`，`next` 由下一层递归产生

```python
def plusList(self, l1, l2, add):
    if not l1 and not l2:
        return None if add == 0 else ListNode(val=add)
    ...
    res = ListNode(val=plusNum)
    res.next = self.plusList(l1, l2, addnum)
    return res
```

**为什么进位只用 0/1？** 每个节点是一位数字（0~9），两个最大 9 相加再加进位 1，最多是 19，进位最多为 1。

### 迭代写法：哑节点 + 进位

递归可以改写成更省空间的迭代版本：

```python
class Solution(object):
    def addTwoNumbers(self, l1, l2):
        dummy = ListNode()
        cur = dummy
        carry = 0
        while l1 or l2 or carry:
            a = l1.val if l1 else 0
            b = l2.val if l2 else 0
            total = a + b + carry
            carry, digit = divmod(total, 10)
            cur.next = ListNode(digit)
            cur = cur.next
            if l1: l1 = l1.next
            if l2: l2 = l2.next
        return dummy.next
```

- 循环条件包含 `carry`，自然处理最高位进位
- 时间 O(max(m, n))，空间 O(1)（不计输出）
- 递归版的时间相同，但递归栈占 O(max(m, n))

## 复杂度

| 写法 | 时间 | 空间 |
|------|:----:|:----:|
| 递归（本仓库） | O(max(m, n)) | O(max(m, n)) 递归栈 |
| 迭代 | O(max(m, n)) | O(1) 额外空间 |

## 代码

```python
# Definition for singly-linked list.
class ListNode(object):
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution(object):
    def addTwoNumbers(self, l1, l2):
        """
        :type l1: Optional[ListNode]
        :type l2: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        return self.plusList(l1, l2, 0)

    def plusList(self, l1, l2, add):
        if not l1 and not l2:
            return None if add == 0 else ListNode(val=add)
        if not l1:
            plusNum = l2.val + add
            l2 = l2.next
        elif not l2:
            plusNum = l1.val + add
            l1 = l1.next
        else:
            plusNum = l1.val + l2.val + add
            l1 = l1.next
            l2 = l2.next
        addnum = 0
        if plusNum >= 10:
            plusNum -= 10
            addnum = 1
        res = ListNode(val=plusNum)
        res.next = self.plusList(l1, l2, addnum)
        return res
```

## 易错点

- **忘记最高位进位**：`5 + 5 = 10` 应该返回 `[0,1]`。递归的终止条件必须处理 `add == 1` 的情况，迭代的 `while` 条件必须包含 `carry`。
- **两个链表长度不同**：一个先走完时，当前位按 0 处理，不能直接返回另一个链表（还要继续处理进位）。本实现用 `if not l1` / `elif not l2` 分支处理。
- **进位判断写成 `> 10`**：应该是 `>= 10`（`9 + 1 = 10` 要进位）。
- **只减一次 10**：本位最大是 `9 + 9 + 1 = 19`，减一次 10 后剩下 9，正确；进位最多 1。
- **节点顺序搞反**：题目链表头是个位，所以从头部开始算就是从低位到高位；不要为了「对齐」而先反转。
- **递归深度**：链表长度最多 100，递归没问题；若数据规模很大，迭代版更稳妥。
- **修改输入链表**：本实现只移动指针、不修改节点值，安全；但递归版逐层创建新节点，原链表保持不变。
- **`ListNode` 定义**：LeetCode 已内置；本仓库为了测试文件能独立运行，在题解中保留了定义，提交时只需保留 `Solution`。
- **空链表**：题目保证两个链表都非空；本实现的递归能正确处理空输入（返回 `None` 或单独的进位节点）。

## 边界测试

| 输入 | 输出 | 说明 |
|------|------|------|
| `[2,4,3] + [5,6,4]` | `[7,0,8]` | 342 + 465 = 807 |
| `[0] + [0]` | `[0]` | 零加零 |
| `[9,9,9,9] + [9,9,9]` | `[8,9,9,0,1]` | 长度不同 + 最高位进位 |
| `[5] + [5]` | `[0,1]` | 简单进位 |
| `[1] + [9,9]` | `[0,0,1]` | 1 + 99 = 100 |
| `[9,9] + [1]` | `[0,0,1]` | 同上，交换顺序 |
