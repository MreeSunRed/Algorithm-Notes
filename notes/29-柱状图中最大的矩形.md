# 柱状图中最大的矩形 (Largest Rectangle in Histogram)

> LeetCode 84 · 难度：困难 · 标签：数组、栈、单调栈

## 题目

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

```
输入: heights = [2,1,5,6,2,3]
输出: 10
解释: 最大的矩形为图中红色区域，面积为 10。
```

## 思路

### 暴力解

枚举每一根柱子作为矩形的「高度」，向左右两边扩展，直到遇到比它矮的柱子为止：

- 对每根柱子向左、右各扫一遍，O(n²)
- 已经能通过大部分数据，但会超时

### 单调栈

关键观察：**以某根柱子 `i` 为高度的最大矩形，左边界是它左边第一个比它矮的柱子，右边界是它右边第一个比它矮的柱子。**

所以问题变成：对每根柱子，快速找到左右两边第一个更矮的位置。这正是**单调栈**擅长的。

维护一个栈，存的是**下标**，栈中高度从栈底到栈顶**非递减**：

1. 当前柱子的高度 `v` 比栈顶柱子矮时，说明栈顶柱子的「右边界」到了
2. 弹出栈顶下标 `j`，它的高度 `heights[j]` 就是矩形高度
3. 左边界是弹出后新的栈顶（左边第一个比它矮的柱子）
4. 宽度 = `i - 左边界 - 1`
5. 用 `heights[j] * width` 更新最大值
6. 重复直到栈顶不高于当前柱子，再把当前下标压栈

### 哨兵技巧

代码在数组首尾各加了一个 `0`：

```python
heights = [0] + heights + [0]
```

这个小技巧解决两个边界问题：

- **左侧的 0**：保证栈永远不为空。弹出某个柱子后，`s[-1]` 一定有值，不用特判「栈空了怎么办」
- **右侧的 0**：保证所有柱子最终都会被弹出。遍历结束后，栈里残留的柱子会在这个 0 面前全部结算，不需要额外写收尾循环

因为所有柱子高度都 ≥ 0，两个 0 不会成为矩形的有效高度（面积为 0），不影响答案。

### 例子走一遍

`heights = [2,1,5,6,2,3]`，加哨兵后为 `[0,2,1,5,6,2,3,0]`：

| 处理 | 动作 | 最大面积 |
|------|------|:--------:|
| 0 | 压栈 | 0 |
| 2 | 压栈 | 0 |
| 1 | 弹 2：高 2，宽 1 → 2 | 2 |
| 5 | 压栈 | 2 |
| 6 | 压栈 | 2 |
| 2 | 弹 6：高 6，宽 1 → 6 | 6 |
| 2 | 弹 5：高 5，宽 2 → 10 | 10 |
| 3 | 压栈 | 10 |
| 0 | 弹 3：高 3，宽 1 → 3 | 10 |
| 0 | 弹 2：高 2，宽 4 → 8 | 10 |
| 0 | 弹 1：高 1，宽 6 → 6 | 10 |

最终答案 10。

## 复杂度

- **时间 O(n)**：每根柱子最多入栈一次、出栈一次
- **空间 O(n)**：栈最多存下所有下标（高度递增时）

## 代码

```python
class Solution(object):
    def largestRectangleArea(self, heights):
        """
        :type heights: List[int]
        :rtype: int
        """
        heights = [0] + heights + [0]
        s = []
        maxH = 0
        for i, v in enumerate(heights):
            while s and heights[s[-1]] > v:
                height = heights[s.pop()]
                width = i - s[-1] - 1
                temp = height * width
                maxH = max(maxH, temp)
            s.append(i)
        return maxH
```

## 易错点

- **`maxH` 初始化为 `-1`（原代码的真实 bug）**：题目允许柱高为 0，输入 `[0]` 的正确答案是 0。若 `maxH = -1`，且没有任何柱子能形成正面积矩形，函数会返回 `-1`，错误。必须初始化为 **0**。这个用例很容易被「至少有一根正高度柱子」的直觉漏掉。
- **漏掉哨兵**：不补左侧 0，弹出后栈可能为空，`s[-1]` 会越界；不补右侧 0，遍历结束时栈里还有柱子没结算，需要额外写循环。两端哨兵让逻辑统一。
- **宽度公式差一**：弹出 `j` 后，新的栈顶是左边界（第一个更矮的位置），当前 `i` 是右边界，中间有效宽度是 `i - s[-1] - 1`。不是 `i - s[-1]`，也不是 `i - j`。
- **弹出后再取 `s[-1]`**：必须先 `pop()` 拿到高度，再用新的栈顶算左边界。顺序反了高度会错。
- **相等高度的处理**：代码用严格的 `>`，相等时不弹出。这样相同高度的柱子会留在栈中，后面被更矮的柱子一起结算，宽度会正确覆盖它们。改成 `>=` 也能做对，但宽度的含义会略有不同，要确保逻辑自洽。
- **栈里存高度而不是下标**：存高度无法计算宽度；必须存下标，再通过 `heights[j]` 取高度。
- **空数组**：LeetCode 保证 `1 <= heights.length`；加哨兵后即使传入空数组也会返回 0，本实现天然兼容。
- **高度为 0**：0 高度的柱子不产生面积，哨兵和它比较时按正常逻辑处理即可。
- **整数溢出**：Python 不会溢出；C++/Java 需要 `long long`（`10^5 × 10^4 = 10^9`，仍在 32 位有符号范围内，但保险起见可用 64 位）。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[2,1,5,6,2,3]` | `10` | 经典用例 |
| `[2,4]` | `4` | 两根柱子，取较高者 |
| `[1]` | `1` | 单根柱子 |
| `[0]` | `0` | **全 0，抓 `maxH` 初始化 bug** |
| `[2,2]` | `4` | 相等高度，合并成宽 2 |
| `[1,1]` | `2` | 相等高度 |
