# 二叉搜索树中第 K 小的元素 (Kth Smallest Element in a BST)

> LeetCode 230 · 难度：中等 · 标签：树、二叉搜索树、中序遍历

## 题目

给定一个二叉搜索树的根节点 `root`，以及一个整数 `k`，返回其中**第 `k` 小**的元素值（`k` 从 1 开始计数）。

```
输入: root = [3,1,4,null,2], k = 1
输出: 1

输入: root = [5,3,6,2,4,null,null,1], k = 3
输出: 3
```

## 思路

### 关键性质：中序遍历就是升序序列

BST 的定义保证「左子树 < 根 < 右子树」，所以按 **左 - 根 - 右** 的顺序访问时，节点值天然单调递增。于是问题变成：

> 在中序遍历中数到第 `k` 个节点，它的值就是答案。

不需要真的把整个中序序列求出来再取下标 —— 数到第 `k` 个就可以停。

### 本仓库实现：中序 DFS + 倒计时

用一个计数器 `self.k` 从 `k` 开始递减，每真正处理一个节点就减 1；减到 1 时当前节点就是答案，记录下来并把 `k` 归零，后续递归入口全部提前返回，相当于全局剪枝。

```python
def dsf(root):
    if root is None:
        return
    if self.k == 0:          # 已经找到答案，剪枝
        return
    dsf(root.left)           # 左
    if self.k > 1:
        self.k -= 1          # 还不是第 k 个，继续数
    elif self.k == 1:        # 当前节点就是第 k 个
        self.k -= 1
        self.min_k = root.val
        return               # 不必再走右子树
    dsf(root.right)          # 右
```

几点说明：

- `self.min_k` 初始化为 `root.val`，保证树至少有一个节点时返回值总是有效。
- 找到答案后把 `k` 置为 0，所有递归入口的 `if self.k == 0: return` 会立即生效，避免继续遍历剩余节点。
- 中序遍历的访问顺序是 `a1 < a2 < ... < an`，第 `i` 次处理节点恰好对应 `ai`，所以计数器减到 1 时 `min_k = ak`。

### 更清晰的写法：迭代中序，命中即返回

递归写法找到答案后仍要逐层退栈。用显式栈可以真正做到「访问到第 `k` 个就停」，也避免了递归深度限制：

```python
class Solution(object):
    def kthSmallest(self, root, k):
        stack = []
        node = root
        while stack or node:
            while node:              # 一路向左，把路径压栈
                stack.append(node)
                node = node.left
            node = stack.pop()       # 弹出当前最小
            k -= 1
            if k == 0:
                return node.val
            node = node.right        # 转向右子树
```

- 时间 O(H + k)：先下探到最左 O(H)，再访问 k 个节点
- 空间 O(H)：栈中最多保存一条从根到叶的路径

### 进阶：Morris 中序遍历（O(1) 空间）

如果面试追问「能否不用额外空间」，可以用 Morris 遍历，借助叶子节点的空右指针临时串成线索：

1. 若当前节点有左子树，找到左子树的最右节点（中序前驱）
2. 前驱的右指针为空 → 指向当前节点，进入左子树
3. 前驱的右指针已指向当前节点 → 说明左子树遍历完，断开线索，访问当前节点，进入右子树

- 时间 O(n)，空间 O(1)
- 代价是会临时修改树的结构，代码也更绕，属于 follow-up 加分项

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 递归中序 + 剪枝（本仓库） | O(H + k)，最坏 O(n) | O(H) 递归栈 | 直观，找到后靠 `k == 0` 剪枝 |
| 迭代中序 | O(H + k)，最坏 O(n) | O(H) 显式栈 | **命中即返回**，不受递归深度限制 |
| Morris 中序 | O(n) | O(1) | 空间最优，代码最绕 |

- `H` 为树高：平衡树 O(log n)，退化成链表时 O(n)
- 最坏情况（`k = n` 且树退化）需要访问全部节点，退化为 O(n)

## 代码

```python
class Solution(object):
    def kthSmallest(self, root, k):
        """
        :type root: Optional[TreeNode]
        :type k: int
        :rtype: int
        """
        self.k = k
        self.min_k = root.val

        def dsf(root):
            if root is None:
                return
            if self.k == 0:
                return
            dsf(root.left)
            if self.k > 1:
                self.k -= 1
            elif self.k == 1:
                self.k -= 1
                self.min_k = root.val
                return
            dsf(root.right)

        dsf(root)
        return self.min_k
```

## 易错点

- **中序顺序写反**：必须是「左 - 根 - 右」才是升序。写成「根 - 左 - 右」得到的是前序，完全无序。
- **`k` 从 1 开始**：计数器和题目一致按 1 基处理，所以判断的是 `k == 1` 而不是 `k == 0`。若改成 0 基，减 1 的位置也要跟着变。
- **忘记重置 `self.k`**：同一个 `Solution` 实例被调用两次时，上一次残留的 `self.k = 0` 会让第二次直接返回错误结果。本实现在方法开头重新赋值。
- **剪枝位置放错**：`if self.k == 0: return` 必须放在递归入口、访问左右子树之前；放在出口的话仍会把整棵树走完。
- **找到答案后还进右子树**：不影响正确性，但会白跑一遍。本实现直接 `return` 掉右子树。
- **递归深度**：节点数最多 10^4，退化成链表时递归深度也是 10^4，可能触发 Python 默认递归上限（约 1000）。面试/提交时迭代中序更稳妥。
- **返回节点还是值**：返回的是 `root.val`，不是节点对象。
- **用排序代替中序**：遍历所有节点排序再取第 k 个是 O(n log n)，完全浪费了 BST 的有序性，属于「能过但不合格」的解法。
- **空树**：题目保证 `1 <= k <= n`，空树不在约束内；若要兼容空树，需先判 `root is None`。
- **函数名 `dsf` 是 `dfs` 的笔误**：实际是深度优先遍历，功能正确，自己写时建议用 `dfs`。
