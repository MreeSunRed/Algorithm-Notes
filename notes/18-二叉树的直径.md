# 二叉树的直径 (Diameter of Binary Tree)

> LeetCode 543 · 难度：简单 · 标签：树、深度优先搜索、二叉树

## 题目

给你一棵二叉树的根节点，返回该树的**直径**。

二叉树的直径是指树中**任意两个节点**之间最长路径的长度。这条路径可能经过根节点，也可能不经过根节点。

两节点之间路径的**长度**用它们之间**边数**表示。

```
输入: root = [1,2,3,4,5]
输出: 3
解释: 最长路径是 [4,2,5] 或 [5,2,1,3]，边数都是 3。

        1
       / \
      2   3
     / \
    4   5
```

## 思路

### 直径在哪里产生

对于任意一个节点，**经过它**的最长路径，一定是从它左子树最深的地方上来，再往右子树最深的地方下去：

```
经过 node 的最长路径（边数） = 左子树高度 + 右子树高度
```

而整棵树的直径，就是所有节点中这个值的最大值 —— 注意路径可能在某个子树内部就达到最长，**不一定要经过根节点**。

### 一次后序遍历

如果对每个节点都单独求左右子树高度，复杂度会退化到 O(n²)。正确的做法是**后序遍历 + 全局打擂台**：

- 递归函数返回当前子树的高度（按节点数计）
- 在返回之前，用 `左高 + 右高 + 1` 更新全局最大值（这是「经过当前节点的路径上的节点数」）
- 最后把「节点数」减 1，得到边数

因为后序遍历保证：处理某个节点时，左右子树都已经处理完、高度已经算好。每个节点只访问一次，O(n)。

### 本仓库实现：全局变量 + 节点数

代码里 `self.diag` 记录「路径上的节点数」，`length(node)` 返回以 `node` 为根的子树高度（节点数）：

```python
d = max(l, r) + 1                  # 当前子树高度
self.diag = max(self.diag, l + r + 1)
return d
```

- `l + r + 1`：左子树高度 + 右子树高度 + 当前节点自己
- 最终 `self.diag - 1`：把节点数换算成边数

**为什么减 1 是对的？** 一条有 `m` 个节点的路径，恰好有 `m - 1` 条边。例如单节点树：`diag = 1`，直径应为 0，`1 - 1 = 0`。

### 也可以直接按边数算

如果不想最后减 1，可以在每个节点直接更新 `左高 + 右高`（此时 `length` 返回的是「以该节点为起点向下的边数」）：

```python
def depth(node):
    if not node:
        return 0
    left = depth(node.left)
    right = depth(node.right)
    self.best = max(self.best, left + right)
    return max(left, right) + 1
```

两种写法等价，只是「高度」的定义差了一个节点。

## 复杂度

- **时间 O(n)**：每个节点恰好被访问一次
- **空间 O(h)**：递归栈深度等于树高；平衡树 O(log n)，退化成链表时 O(n)

## 代码

```python
class Solution(object):
    def diameterOfBinaryTree(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: int
        """
        self.diag = 0

        def length(root):
            if root == None:
                return 0
            l = length(root.left)
            r = length(root.right)
            d = max(l, r) + 1
            self.diag = max(self.diag, l + r + 1)
            return d

        length(root)
        return self.diag - 1
```

## 易错点

- **以为直径一定经过根节点**：反例是一棵左右严重不平衡的树，最长路径可能完全落在某个子树内部。所以必须在**每个节点**都更新最大值，而不是只在根节点算一次。
- **边数和节点数混淆**：题目要求的是**边数**。本实现用节点数统计，最后 `- 1`；如果直接返回 `self.diag`，单节点树会得到 1（错误，应为 0）。
- **空树**：LeetCode 保证至少 1 个节点。若允许空树，本实现会返回 `-1`；健壮版本应在开头加 `if not root: return 0`。
- **`self.diag` 忘记重置**：如果不在方法开头写 `self.diag = 0`，同一个 `Solution` 实例多次调用会累加上一次的结果。本实现每次都重置，安全。
- **把高度定义搞混**：`length` 返回的是「节点数」意义下的高度，空节点返回 0。若改成边数意义，更新公式也要同步改。
- **递归深度**：退化链表有 O(n) 层递归，节点数很大时可能触发 Python 递归上限，可改用迭代后序遍历。
- **左右子树高度要分别保存**：先算 `l`、再算 `r`，不要用同一个变量覆盖，否则更新 `l + r` 时数据已经丢了。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[1]` | `0` | 单节点，直径为 0 条边 |
| `[1,2]` | `1` | 两个节点，1 条边 |
| `[1,2,3]` | `2` | 路径 2-1-3 |
| `[1,2,3,4,5]` | `3` | 经典用例：4-2-1-3 或 5-2-1-3 |
| `[1,2,null,3,null,4]` | `3` | 退化成链：4-3-2-1 |
