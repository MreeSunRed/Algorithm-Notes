# 验证二叉搜索树 (Validate Binary Search Tree)

> LeetCode 98 · 难度：中等 · 标签：树、深度优先搜索、二叉搜索树

## 题目

给你一个二叉树的根节点 `root`，判断它是否是一个有效的**二叉搜索树（BST）**。

有效 BST 定义如下：

- 节点的**左子树**只包含**严格小于**当前节点的数
- 节点的**右子树**只包含**严格大于**当前节点的数
- 所有左子树和右子树自身必须也是二叉搜索树

```
输入: root = [2,1,3]
输出: true

输入: root = [5,1,4,null,null,3,6]
输出: false
解释: 根节点的值是 5，但右子树的值是 4；且右子树的左孩子是 3，也小于 5。
```

## 思路

### 常见错误：只比较直接孩子

很多人第一反应是写：

```python
if root.left and root.left.val >= root.val: return False
if root.right and root.right.val <= root.val: return False
return isValidBST(root.left) and isValidBST(root.right)
```

这对下面的树会误判为 `true`：

```
      5
     / \
    1   6
       / \
      3   7
```

节点 6 的左孩子是 3，局部看 `3 < 6` 没问题；但 3 位于 5 的**右子树**中，必须大于 5，所以整棵树不是 BST。

**结论**：BST 的约束是「整棵子树的取值范围」，不是「和直接父节点比较」。

### 上下界递归（本仓库实现）

给递归函数带上一个**开区间** `(low, high)`，表示当前节点允许的取值范围：

- 根节点的范围是 `(-∞, +∞)`
- 进入左子树时，上界收紧为当前节点的值：`(low, root.val)`
- 进入右子树时，下界收紧为当前节点的值：`(root.val, high)`
- 任何节点不满足 `low < root.val < high`，整棵树就不是 BST

```python
def bsf(root, low, high):
    if not root:
        return True
    if low is not None and root.val <= low:
        return False
    if high is not None and root.val >= high:
        return False
    return bsf(root.left, low, root.val) and bsf(root.right, root.val, high)
```

**为什么用 `None` 而不是 `INT_MIN` / `INT_MAX` 作为无穷？**

节点的值可以恰好等于 32 位整数的边界。若用 `INT_MIN` 作为初始下界，那么值为 `INT_MIN` 的节点会被误判为非法。`None` 表示「这一侧没有约束」，可以安全地处理任意整数。

**为什么是严格不等号？** BST 不允许重复值，所以 `root.val <= low` 和 `root.val >= high` 都要返回 `False`。

### 另一种写法：中序遍历严格递增

BST 的中序遍历结果一定**严格递增**。反过来，中序遍历严格递增的二叉树也一定是 BST。所以可以只做一次中序遍历，检查序列是否严格递增：

```python
class Solution(object):
    def isValidBST(self, root):
        self.prev = None

        def inorder(node):
            if not node:
                return True
            if not inorder(node.left):
                return False
            if self.prev is not None and node.val <= self.prev:
                return False
            self.prev = node.val
            return inorder(node.right)

        return inorder(root)
```

- 时间 O(n)，空间 O(h)
- 逻辑更贴近 BST 的定义，但需要维护前驱值
- 也可以用迭代中序遍历，避免递归深度问题

## 复杂度

| 写法 | 时间 | 空间 |
|------|:----:|:----:|
| 上下界递归（本仓库） | O(n) | O(h) |
| 中序遍历（递归 / 迭代） | O(n) | O(h) |

- 每个节点只访问一次
- `h` 为树高：平衡树 O(log n)，退化成链表时 O(n)

## 代码

```python
class Solution(object):
    def isValidBST(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: bool
        """
        def bsf(root, low, high):
            if not root:
                return True
            if low is not None and root.val <= low:
                return False
            if high is not None and root.val >= high:
                return False
            return bsf(root.left, low, root.val) and bsf(root.right, root.val, high)

        return bsf(root, None, None)
```

## 易错点

- **只比较直接孩子**：必须把祖先的约束一路传下来。经典反例 `[5,1,4,null,null,3,6]`，右子树的 3 虽然小于 4，却小于根节点 5，整棵树非法。
- **用 `INT_MIN` / `INT_MAX` 当哨兵**：节点值可能等于这两个边界，会被误判。用 `None`、`-inf/+inf` 或独立的「无约束」标记。
- **判空条件写成 `if low:`**：`low = 0` 是合法下界，但假值会跳过检查。必须写 `if low is not None`。
- **用非严格不等号**：BST 不允许重复值，遇到相等的值要返回 `False`，所以是 `<=` / `>=` 判非法。
- **左右子树的边界传反**：左子树继承下界、用父值作上界；右子树用父值作下界、继承上界。不能把两者对调。
- **空树**：空树视为有效 BST，返回 `True`。题目一般保证至少一个节点，但写法上应兼容。
- **中序遍历只检查「非递减」**：必须严格递增；遇到相等值也要判非法。
- **递归深度**：最坏情况是退化链表，递归深度 O(n)。LeetCode 节点数可达 10^4，Python 可能触发递归上限；可以改迭代中序遍历。
- **函数名 `bsf` 有误导性**：它实际是深度优先（DFS）的上下界检查，不是广度优先（BFS）。功能正确，改名 `dfs` 更清晰。
- **没有返回值的分支**：确保所有路径都返回 `True` 或 `False`，不要漏掉右子树的结果。

## 边界测试

| 输入 | 输出 | 说明 |
|------|:----:|------|
| `[2,1,3]` | `true` | 最简单的合法 BST |
| `[5,1,4,null,null,3,6]` | `false` | 右子树内部有小于根的值 |
| `[5,4,6,null,null,3,7]` | `false` | 右子树的左孩子 3 小于 5 |
| `[2,2,2]` | `false` | 重复值非法 |
| `[1]` | `true` | 单节点 |
| `[]` | `true` | 空树视为合法 |
| `[2147483647]` | `true` | 值为 INT_MAX |
| `[-2147483648]` | `true` | 值为 INT_MIN |
