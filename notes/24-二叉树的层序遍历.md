# 二叉树的层序遍历 (Binary Tree Level Order Traversal)

> LeetCode 102 · 难度：中等 · 标签：树、广度优先搜索、二叉树

## 题目

给你二叉树的根节点 `root`，返回其节点值的**层序遍历**（即逐层地、从左到右访问所有节点）。

```
输入: root = [3,9,20,null,null,15,7]
输出: [[3],[9,20],[15,7]]

      3
     / \
    9  20
      /  \
     15   7
```

## 思路

### 为什么用队列

层序遍历要求**先访问完第 `d` 层，才能访问第 `d+1` 层**。这和队列的先进先出正好吻合：

- 处理一个节点时，把它的左右孩子依次入队
- 队首永远是「当前层最早被加入的节点」
- 只要按层处理，出队顺序天然就是从上到下、从左到右

### 标准写法：按层快照队列长度

最直接的实现是在每一层开始时记下 `len(queue)`，这一轮只弹出这么多节点：

```python
from collections import deque

class Solution(object):
    def levelOrder(self, root):
        if not root:
            return []
        res = []
        q = deque([root])
        while q:
            level = []
            for _ in range(len(q)):     # 只处理当前层
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level)
        return res
```

**`for _ in range(len(q))` 是关键**：`len(q)` 在循环开始前就固定下来，新入队的孩子属于下一层，不会被本轮处理。如果写成 `while q` 的内层循环，就会把所有层混在一起。

- 时间 O(n)，空间 O(w)（`w` 为树的最大宽度）

### 本仓库实现：先复制树并标高层号

代码走了另一条路：先用 `copy` 递归复制整棵树，同时给每个新节点记录 `height`（根为 1），并把最大高度存到 `self.maxh`；然后用普通 BFS 遍历复制出来的树，按 `height - 1` 把节点值放进对应的结果列表。

```python
def copy(root1, h):
    if not root1:
        return None
    self.maxh = max(self.maxh, h)
    root2 = TNode(val=root1.val, height=h)
    root2.left = copy(root1.left, h + 1)
    root2.right = copy(root1.right, h + 1)
    return root2
```

在 BFS 中，每个节点直接带着自己的层号，所以不需要维护「当前在第几层」：

```python
res = [[] for _ in range(self.maxh)]
...
res[p.height - 1].append(p.val)
```

**正确性没有问题**，但代价比较明显：

- 额外复制了一整棵树，空间多 O(n)
- 多了一次递归遍历
- 需要自定义 `TNode` 和 `height` 字段

标准写法不需要复制，也不需要层号，直接利用「队列长度 = 当前层节点数」即可。

### 另一种写法：DFS + 层号

也可以用 DFS，把节点按深度追加到 `res[depth]`：

```python
def dfs(node, depth):
    if not node:
        return
    if depth == len(res):
        res.append([])
    res[depth].append(node.val)
    dfs(node.left, depth + 1)
    dfs(node.right, depth + 1)
```

- 时间 O(n)，空间 O(h)
- 结果顺序依然是层序，但访问顺序是 DFS，不如 BFS 直观

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 标准 BFS（按层快照长度） | O(n) | O(w) | 最优，无需复制 |
| 本仓库（复制 + 层号） | O(n) | O(n) | 正确，但多一棵复制树 |
| DFS + 层号 | O(n) | O(h) | 递归实现，顺序仍是层序 |

- `n` 是节点数，`w` 是最大宽度，`h` 是树高
- 结果数组本身占 O(n)，不计入额外空间时，标准 BFS 的额外空间是队列 O(w)

## 代码

```python
from collections import deque

class TNode(object):
    def __init__(self, val=0, left=None, right=None, height=None):
        self.val = val
        self.left = left
        self.right = right
        self.height = height


class Solution(object):
    def levelOrder(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: List[List[int]]
        """
        def copy(root1, h):
            if not root1:
                return None
            self.maxh = max(self.maxh, h)
            root2 = TNode(val=root1.val, height=h)
            root2.left = copy(root1.left, h + 1)
            root2.right = copy(root1.right, h + 1)
            return root2

        self.maxh = 0
        root2 = copy(root, 1)
        q = deque()
        q.append(root2)
        res = [[] for _ in range(self.maxh)]
        while q:
            p = q.popleft()
            if not p:
                continue
            res[p.height - 1].append(p.val)

            if p.left:
                q.append(p.left)
            if p.right:
                q.append(p.right)
        return res
```

## 易错点

- **内层循环没有固定当前层长度**：如果写成 `while q:` 然后一直弹出，某一层的孩子入队后会被同一轮处理，结果变成一维列表。必须先用 `for _ in range(len(q))` 快照。
- **空树**：`root = null` 应返回 `[]`。本仓库的 `copy(None, 1)` 返回 `None`，`res` 为空，BFS 遇到 `None` 直接跳过，返回 `[]`，正确。
- **把 `None` 孩子入队**：标准写法只在孩子非空时入队，避免无意义的空节点处理。本仓库把 `None` 根入队并用 `if not p: continue` 跳过，属于特判。
- **层号从 0 还是 1 开始**：本仓库从 1 开始，所以写入 `res[height - 1]`；若从 0 开始，则直接用 `res[height]`。两套约定不能混用。
- **`self.maxh` 忘记重置**：`levelOrder` 开头必须写 `self.maxh = 0`，否则同一个 `Solution` 实例多次调用会残留上一次的高度，导致结果列表过长或索引错误。
- **复制树的额外开销**：本仓库为了记录层号复制了整棵树。标准 BFS 不需要复制，也不需要自定义节点类型，面试中应优先给出标准写法。
- **DFS 写法的追加时机**：`if depth == len(res): res.append([])` 要放在访问节点之前，否则数组还没扩展到该层就会索引越界。
- **左右孩子的顺序**：先左后右入队，才能保证每层从左到右；顺序反了会得到从右到左的层序。
- **递归深度**：复制树和 DFS 写法都有 O(h) 递归，退化链表时可能触发递归上限。
