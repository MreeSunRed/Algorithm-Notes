# 爬楼梯 (Climbing Stairs)

> LeetCode 70 · 难度：简单 · 标签：动态规划、记忆化搜索、数学

## 题目

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。每次你可以爬 **1 或 2** 个台阶。问有多少种不同的方法可以爬到楼顶。

```
输入: n = 2
输出: 2
解释: 1 + 1、2

输入: n = 3
输出: 3
解释: 1 + 1 + 1、1 + 2、2 + 1
```

## 思路

### 从最后一步倒推

想爬到第 `n` 阶，最后一步只有两种可能：

- 从第 `n - 1` 阶爬 **1** 阶上来
- 从第 `n - 2` 阶爬 **2** 阶上来

这两类方案互不重叠，且覆盖了所有走法，所以：

```
f(n) = f(n - 1) + f(n - 2)
```

边界：`f(1) = 1`，`f(2) = 2`（两阶可以一次跨 2 阶，也可以分两次走）。

这正是**斐波那契数列**的递推式，只是起点不同。

### 本仓库实现：自底向上 DP

`dp[i]` 表示到达第 `i` 阶的方法数。初始化 `dp[1] = 1`、`dp[2] = 2`，然后从 3 递推到 `n`：

```python
dp = [0] * (n + 3)
dp[2] = 2
dp[1] = 1
i = 3
while i <= n:
    dp[i] = dp[i - 1] + dp[i - 2]
    i += 1
```

**为什么数组开 `n + 3` 而不是 `n + 1`？** 因为无论 `n` 是 1 还是 2，代码都会先给 `dp[2]` 赋值。若只开 `n + 1` 个元素，`n = 1` 时 `dp[2]` 就越界了。多开两格让边界情况统一，不需要额外特判。

- 时间 O(n)：一次线性递推
- 空间 O(n)：保存了整张 DP 表

### 空间优化：滚动变量

注意到 `dp[i]` 只依赖前两项，完全不需要保存整张表：

```python
class Solution(object):
    def climbStairs(self, n):
        if n <= 2:
            return n
        a, b = 1, 2          # a = f(i-2), b = f(i-1)
        for _ in range(3, n + 1):
            a, b = b, a + b
        return b
```

- 时间 O(n)，空间 O(1)
- 面试中给出这个写法能体现对状态依赖的分析

### 其他角度

- **记忆化递归**：`f(n) = f(n-1) + f(n-2)` 加缓存，时间 O(n)、空间 O(n)；裸递归是 O(2^n)，`n = 45` 就超时。
- **矩阵快速幂**：把递推写成矩阵乘法，时间 O(log n)，适合 `n` 极大的追问。
- **通项公式（Binet）**：`f(n) = (φ^(n+1) - ψ^(n+1)) / √5`，有浮点误差，一般不推荐。
- **组合计数**：枚举 2 阶台阶的个数 `k`，答案为 `Σ C(n - k, k)`，时间 O(n)。

## 复杂度

| 写法 | 时间 | 空间 | 特点 |
|------|:----:|:----:|------|
| 自底向上 DP（本仓库） | O(n) | O(n) | 直观，适合讲清状态定义 |
| 滚动变量 | O(n) | O(1) | **空间最优**，面试首选 |
| 记忆化递归 | O(n) | O(n) | 从定义直接翻译，需注意递归深度 |
| 矩阵快速幂 | O(log n) | O(1) | `n` 很大时的进阶解法 |

## 代码

```python
class Solution(object):
    def climbStairs(self, n):
        """
        :type n: int
        :rtype: int
        """
        dp = [0] * (n + 3)
        dp[2] = 2
        dp[1] = 1
        i = 3
        while i <= n:
            dp[i] = dp[i - 1] + dp[i - 2]
            i += 1
        return dp[n]
```

## 易错点

- **`n = 1` 的边界**：此时循环不执行，直接返回预置的 `dp[1] = 1`，正确；但数组必须开得下 `dp[2]`。
- **数组开太小**：`dp = [0] * (n + 1)` 在 `n = 1` 时访问 `dp[2]` 会越界。本实现开 `n + 3` 统一处理。
- **边界值写错**：`f(2) = 2`，不是 1。两阶既可以一次跨 2 阶，也可以走两次 1 阶。
- **递推方向搞反**：必须从已知的小问题往大问题推（3 → n），不能从 `n` 往下展开而不加记忆化。
- **裸递归不加缓存**：`f(n-1) + f(n-2)` 会重复计算大量子问题，复杂度 O(2^n)，`n = 45` 直接超时。
- **循环条件漏等号**：`while i <= n` 而不是 `i < n`，否则 `dp[n]` 永远算不到。
- **返回方法数而不是台阶数**：题目问的是走法总数，不是 `n`。
- **把「1 或 2 阶」理解成任意阶**：每次只能走 1 阶或 2 阶，这是递推成立的前提。
- **忘记空间可以优化**：本实现 O(n) 空间不是最优，面试应主动补一句「可以用两个变量滚动到 O(1)」。
